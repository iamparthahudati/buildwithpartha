## Completed behavior

Built the Today page header and responsive metric strip and mounted them at the protected `/life-os/app/today` route.

- `TodayHeader` derives `Good morning`, `Good afternoon`, or `Good evening` from the authenticated user's confirmed IANA timezone, includes the display name, formats the local date with the confirmed locale, displays the timezone, and renders the approved helper `See what needs attention and choose what to do next.`
- The header's `Quick Add` button invokes the same shell-owned `QuickAddDialog` as the TopBar. `AppShell` shares that action with routed screens through typed React Router outlet context; the Today feature does not create a second dialog or own shell state.
- `TodayMetricStrip` composes six existing shared `MetricCard` instances in the approved order: today's focus, tasks today, scheduled time, focus time, active projects, and week progress.
- Every metric accepts an independent discriminated ready/loading/empty/error state and an optional metric-specific retry action. One failed metric cannot replace or suppress another.
- The routed foundation state uses calm, truthful zero-data messages rather than fabricated values or permanent loading while LOS-0615 still owns aggregation-endpoint integration.
- The strip renders as a six-column grid at wide desktop widths, wraps as space narrows, and becomes a horizontally scrollable card row below 30rem without causing page-level horizontal overflow.
- Development catalog specimens cover morning/evening headers, loading/ready/mixed metric strips, and the composed header with approved helper and empty states.
