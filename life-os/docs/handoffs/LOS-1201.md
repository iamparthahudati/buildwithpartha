## Completed behavior

- **Notes API Implementation**:
  - Implemented database migrations for `notes`, `note_labels`, and `note_links`.
  - Created domain model `Note` along with `NoteLink`, `NoteLinkTargetType`, `NoteQuery`, `NoteQueryResult`, and `NoteRepository` interface.
  - Implemented JPA repository mapping `NoteEntity` and `NoteLinkEntity` with criteria-based dynamic filtering.
  - Built transactional `NoteService` to handle CRUD operations, pinning, unpinning, archiving, restoring, labels validation, and entity link ownership validation.
  - Exposed REST endpoints on `NoteController` (under `/life-os/api/v1/notes`) for all operations.
  - Redacted note body/query content in all `toString()` overrides of domain objects, commands, and request/response payloads to prevent sensitive content logging.
  - Extracted `GoalOwnershipValidator` from the `goal` domain into a domain-neutral contract interface under `common/goal` implemented by `DefaultGoalOwnershipValidator` to avoid package boundary rule violations.
