## Completed behavior

### Comprehensive Security Headers & CSP Specification (`51-SECURITY-HEADERS-AND-CSP.md`)

Established defense-in-depth HTTP security header and Content Security Policy (CSP) policies across all three execution tiers: Edge reverse proxy (Caddy / Cloudflare), Static Web container (Nginx), and REST API service (Spring Boot).

1. **Content Security Policy (CSP)**:
   - Eliminated unsafe inline/eval script execution permissions (`script-src 'self'`).
   - Allowed dynamic design tokens and theme styling with `style-src 'self' 'unsafe-inline'`.
   - Allowed same-origin images, base64 data URIs, and memory blob URLs with `img-src 'self' data: blob:`.
   - Restricted fonts and API connect targets with `font-src 'self'` and `connect-src 'self'`.
   - Blocked framing across all origins with `frame-ancestors 'none'`.
   - Constrained base URIs and form targets with `base-uri 'self'` and `form-action 'self'`.
   - Enforced automatic HTTPS upgrade with `upgrade-insecure-requests`.
   - Configured dedicated ultra-restrictive API-level CSP in Spring Boot: `default-src 'none'; frame-ancestors 'none'`.

2. **HTTP Strict Transport Security (HSTS)**:
   - Enforced 1-year HSTS across all subdomains with preload eligibility: `Strict-Transport-Security "max-age=31536000; includeSubDomains; preload"`.

3. **MIME Sniffing & Anti-Framing Protection**:
   - Disabled MIME type sniffing via `X-Content-Type-Options: nosniff`.
   - Completely disabled framing and clickjacking via `X-Frame-Options: DENY`.

4. **Hardware & Sensitive API Restriction**:
   - Restricted device access via `Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=(), usb=(), screen-wake-lock=()`.

5. **Cross-Origin Isolation & Modern XSS Defaults**:
   - Disabled legacy buggy XSS auditors with `X-XSS-Protection: 0`.
   - Enforced cross-origin isolation with `Cross-Origin-Opener-Policy: same-origin` and `Cross-Origin-Resource-Policy: same-origin`.
   - Maintained `Referrer-Policy: strict-origin-when-cross-origin`.
