## Completed behavior

Added native frontend and backend factories for deterministic User, Project, Task and time fixtures. Both stacks share the same fixed UUIDs and UTC instant, reserved `example.test` identity data, approved neutral Project/Task titles, canonical stored statuses and default `Asia/Kolkata` timezone.

Frontend factory results are frozen and support field-specific overrides. Backend factories return immutable records through fresh configurable builders. Time factories validate or require IANA timezones and derive the local date from the chosen instant and zone instead of relying on a machine clock or default timezone.
