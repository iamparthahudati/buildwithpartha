## Completed behavior

Implemented the profile and localization settings screens and panels connecting to user profile & preferences endpoints (LOS-0513), per `docs/wireframes/02-SETTINGS-SECURITY.md`, `docs/23-NAVIGATION-AND-ROUTES.md`, and `docs/backlog/EPIC-05-IDENTITY.md`:

- **User Feature Foundations (`apps/web/src/features/user`)**:
  - `model/profileValidation.ts`: Client-side validation logic for profile (display name required, max 100 characters) and localization settings (valid IANA timezone/UTC, supported locale, week start between 1 Monday and 7 Sunday).
  - `model/profileFieldErrors.ts`: Maps backend ProblemDetails (`errors: [{ field, code }]`) into user-facing field error messages.
  - `model/formatsPreview.ts`: Immediate live recalculation and formatting of date, time, relative timestamps, numbers, and week start names according to selected timezone and locale.
  - `hooks/useUserProfile.ts`: TanStack Query hook fetching user profile from `/user/profile`.
  - `hooks/useUpdateUserProfile.ts`: TanStack Query mutation hook sending `PUT /user/profile`, automatically updating active session state in `AuthSessionProvider`.
  - `hooks/useUserPreferences.ts`: TanStack Query hook fetching user preferences from `/user/preferences`.
  - `hooks/useUpdateUserPreferences.ts`: TanStack Query mutation hook sending `PUT /user/preferences`.
  - Unit tests in `profileValidation.test.ts`, `formatsPreview.test.ts`, and `userHooks.test.tsx`.

- **Settings Feature UI (`apps/web/src/features/settings`)**:
  - `components/ProfileSettingsPanel.tsx`: Profile settings tab displaying avatar preview, verified permanent email (read-only), editable display name, inline field validation, error summary, and save actions with dirty state tracking.
  - `components/LocalizationSettingsPanel.tsx`: Localization settings tab featuring searchable IANA timezone combobox with device timezone and UTC shortcuts, locale select, week start day select, warning alert upon timezone modification, and a live formatted date/time preview card.
  - `components/SettingsScreen.tsx`: Top-level tabbed settings screen managing Profile, Localization, Security, and Data & Privacy sections, handling loading skeletons and error retry states.
  - `components/settings-screen.css`: Token-only responsive styles.
  - Component tests in `ProfileSettingsPanel.test.tsx`, `LocalizationSettingsPanel.test.tsx`, and `SettingsScreen.test.tsx`.
