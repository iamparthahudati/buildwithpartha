## Completed behavior

Created the first standalone, executable LifeOS backend under `apps/api` using Java 21 and Spring Boot 4.1.0. The service is packaged as `life-os-api.jar`, owns the `/life-os/api/v1` servlet context and remains independent from the existing main website.

The application includes the required web MVC, Bean Validation, Spring Security, Spring Data JPA, Actuator, Flyway, mail and PostgreSQL foundations. It introduces no product endpoint, schema migration or authentication behavior before their assigned tickets.

## Files and contracts changed

- Added the Spring Boot/Java entry point at package root `tech.buildwithpartha.lifeos`.
- Added a Gradle Kotlin build and Gradle 9.5.1 wrapper with the official distribution SHA-256 checksum.
- Added Boot-managed PostgreSQL/Flyway runtime dependencies and modular starter test dependencies.
- Added externalized database/mail/server configuration with JPA schema validation, Flyway ownership, disabled Open Session in View and minimal Actuator exposure.
- Added an isolated H2 PostgreSQL-mode test profile and context test that needs no external secret, database or mail service.
- Documented JDK selection, wrapper commands, configuration boundaries and executable archive location.
