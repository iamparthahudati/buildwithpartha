# LOS-0909 handoff

- Status: Done

## Completed behavior

- Added authenticated `GET /calendar/events` for an inclusive local-date range interpreted in a required IANA timezone.
- Aggregated canonical Time Blocks, due Tasks, and Milestones without creating Calendar-owned copies.
- Returned stable event IDs plus the canonical UUID `sourceId` and `sourceType`, enabling LOS-0911 to open the true source record.
- Added repeatable source filters for `TIME_BLOCK`, `TASK_DUE`, `MILESTONE`, `HABIT`, and `REVIEW`; omitted filters select all contract values.
- Enforced owner scoping inside every source query. Task reads also exclude deleted/archived Tasks, and Milestone reads require an active owner-matched Project.
- Preserved timed/all-day distinctions: Time Blocks keep start/end instants, due Tasks keep their due instant, and Milestones keep their local date.
- Added deterministic ordering across sources and explicit `truncated` metadata with a maximum 500-event result.
- Limited one request to 62 local dates and converted boundaries with `ZoneId`, including DST-short and DST-long days.
- Added a domain-neutral source adapter contract so later Habit and Review persistence can contribute real occurrences without changing the Calendar API.
