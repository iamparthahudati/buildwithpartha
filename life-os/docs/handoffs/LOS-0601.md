## Completed behavior

Implemented responsive sidebar navigation component for LifeOS per `docs/backlog/EPIC-06-SHELL-TODAY.md`, `docs/23-NAVIGATION-AND-ROUTES.md`, `docs/22-INFORMATION-ARCHITECTURE.md`, and `docs/wireframes/02-SHELL-TODAY.md`:

- **Destinations & Information Architecture (`apps/web/src/components/navigation/navigationDestinations.ts`)**:
  - Defined `NavDestination` and `NavGroup` data contracts.
  - Implemented the 4 canonical groups and 14 destinations per Information Architecture:
    - **Execute**: Today (`/life-os/app/today`), Tasks (`/life-os/app/tasks`), Time Blocks (`/life-os/app/time-blocks`), Projects (`/life-os/app/projects`).
    - **Plan**: Sprints (`/life-os/app/sprints`), Week Planner (`/life-os/app/week-planner`), Calendar (`/life-os/app/calendar`), Goals (`/life-os/app/goals`).
    - **Capture and grow**: Notes (`/life-os/app/notes`), Brain Dump (`/life-os/app/brain-dump`), Habits (`/life-os/app/habits`).
    - **Reflect**: Progress (`/life-os/app/progress`), Reports (`/life-os/app/reports`), Reviews (`/life-os/app/reviews`).
  - Active route resolver `isNavDestinationActive(currentPath, destinationHref)` supporting exact root and nested sub-route matching.
  - Unit tests in `navigationDestinations.test.ts`.

- **Persistence Helper (`apps/web/src/components/navigation/sidebarStorage.ts`)**:
  - Safe browser `localStorage` persistence helper (`lifeos:sidebar:collapsed`) for remembering non-sensitive device collapse state.
  - Handles disabled storage, restricted iframe contexts, and quota errors gracefully.
  - Unit tests in `sidebarStorage.test.ts`.

- **Styling & Tokens (`apps/web/src/components/navigation/sidebar.css`)**:
  - Strict adherence to `--lifeos-*` semantic tokens (surfaces, spacing, borders, focus rings, transitions, typography).
  - Responsive desktop sidebar width (`--lifeos-layout-sidebar-width`: 240px) and compact collapsed rail (`--lifeos-layout-sidebar-rail-width`: 64px).
  - Left active indicator bar with primary tone and subtle background tint on active destination links.
  - Keyboard focus visibility with token focus rings on all links and collapse toggle buttons.

- **Component Implementation (`apps/web/src/components/navigation/Sidebar.tsx`)**:
  - **Brand Wordmark**: LifeOS `Logo` atom linking to `/life-os/app/today` (lockup variant when expanded, symbol variant when collapsed).
  - **Skip Link**: Dedicated `.lifeos-skip-link` rendered as first tab stop pointing to `#main-content` (or custom ID).
  - **Grouped Items**: Semantic `<nav>` landmark, headings with `aria-labelledby` group linking, active destination state marked with `aria-current="page"`.
  - **Expand / Collapse**: Toggle button with `ChevronsLeft` / `ChevronsRight` icons, `aria-expanded`, accessible labels, and tooltips in rail mode.
  - **Rail Mode**: Tooltip wrappers on icon buttons in collapsed state for accessible naming and hover/focus discovery.
  - **Mobile Drawer Mode**: Integrated with `@components/feedback` `Drawer` (`placement="start"`) for small viewports with focus trapping and backdrop dismissal.
  - **Slots & Callbacks**: Custom `footer` slot (e.g. settings link, user avatar, mini player), `headerAction` slot, and `onNavigate` handler.
  - Unit & accessibility tests in `Sidebar.test.tsx` (17 test cases, 0 axe violations).

- **Catalog Demos & Registry (`apps/web/src/catalog/`)**:
  - `SidebarExpandedDemo`: Full persistent navigation demo with active destination updates.
  - `SidebarCollapsedDemo`: Compact rail navigation with hover/focus tooltips.
  - `SidebarInteractiveDemo`: Interactive collapse toggling with remembered local storage state.
  - `SidebarDrawerDemo`: Mobile slide-out drawer trigger and navigation flow.
  - Registered under "Composed" group in `navigationEntries.tsx`.

- **Module Public Entrypoint (`apps/web/src/components/navigation/index.ts`)**:
  - Clean export surface for `Sidebar`, `SidebarProps`, `NavDestination`, `NavGroup`, `DEFAULT_NAV_GROUPS`, `getStoredSidebarCollapsed`, `setStoredSidebarCollapsed`, `isNavDestinationActive`.
