## Completed behavior

- Built the full Goal UI component suite in `apps/web/src/features/goals/`:
  - `model/goal.ts`: Domain models (`Goal`, `GoalCheckIn`, `GoalLink`, `GoalDetail`, `GoalSummaryCounts`) and calculation utilities (`calculateGoalProgressPercentage`, `formatGoalProgressValue`, `getGoalProgressExplanation`) for `PERCENTAGE`, `NUMERIC`, `MILESTONE`, and `BINARY` progress types.
  - `GoalCard.tsx` (`goal-card.css`, `GoalCard.test.tsx`): Goal card displaying category, status badge, progress percentage bar with numeric values, explicit progress calculation explanation, check-in cadence, target date, linked work chips, and contextual actions (`Check In`, `Pause`, `Resume`, `Mark Complete`, `Edit`, `Archive`).
  - `GoalRow.tsx` (`goal-row.css`, `GoalRow.test.tsx`): Compact row layout displaying goal title, category, progress bar, value summary, status badge, and quick action buttons.
  - `ProgressEditor.tsx` (`progress-editor.css`, `ProgressEditor.test.tsx`): Interactive progress editor with current value input, quick increment buttons (+5%, +25%, +1, +5, +10), check-in note textarea, and explicit calculation explanation callout.
  - `CheckInFormDialog.tsx` (`check-in-form.css`, `CheckInFormDialog.test.tsx`): Form dialog for logging a goal check-in with new value, date, and note.
  - `CheckInHistory.tsx` (`check-in-history.css`, `CheckInHistory.test.tsx`): Timeline list of past check-ins with dates, values, delta changes, notes, and zero-check-in empty state.
  - `GoalLinkedWorkList.tsx` (`goal-linked-work.css`, `GoalLinkedWorkList.test.tsx`): Linked work items manager showing connected projects, tasks, and habits with target type badges, inline add link control, and unlink action.
  - `GoalMetricSummary.tsx` (`goal-metric-summary.css`, `GoalMetricSummary.test.tsx`): Summary cards displaying total goals, completed goals, paused goals, and average progress % with loading, error, and empty states.
  - `GoalEmptyState.tsx` & `GoalErrorState.tsx`: Zero-shame empty state and error state.
- Re-exported all goal components and types from `apps/web/src/features/goals/index.ts`.
- Created interactive catalog specimens in `apps/web/src/catalog/GoalsDemos.tsx`, `ComposedDemos.tsx`, and registered them in `composedEntries.tsx`.
