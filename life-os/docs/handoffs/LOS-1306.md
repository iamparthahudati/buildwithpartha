## Completed behavior

- **Recurrence Occurrence Engine (`tech.buildwithpartha.lifeos.task.domain.RecurrenceOccurrenceEngine`)**:
  - Implemented pure domain occurrence calculation engine supporting all frequency modes (`DAILY`, `WEEKLY`, `MONTHLY`, `WEEKDAY`, `INTERVAL`, `AFTER_COMPLETION`).
  - Implemented end mode boundaries (`NEVER`, `UNTIL_DATE`, `COUNT`), month-end day clamping (e.g. Feb 28/29, April 30 for 31st target), and leap year calculations.
  - Implemented timezone/DST safe date and due timestamp conversions in series target time zones.

- **Idempotent Occurrence Generation Service & Job (`tech.buildwithpartha.lifeos.task.application`)**:
  - Implemented `RecurrenceGenerationService` which calculates candidate occurrences for active series up to a target horizon date.
  - Enforced strict idempotency and duplicate prevention by cross-checking existing tasks (`recurringSeriesId`, `recurrenceOccurrenceDate`) and series exception records (`SKIPPED`, `RESCHEDULED`, `DELETED`, `OVERRIDDEN`).
  - Integrated task completion trigger: completing a task belonging to an `AFTER_COMPLETION` series automatically computes and creates the next occurrence `intervalValue` days after completion.
  - Implemented `@Scheduled` `RecurrenceGenerationJob` to periodically generate due occurrences across active series.

- **Recurrence Series Service & Scope Mutations (`tech.buildwithpartha.lifeos.task.application.RecurringTaskSeriesService`)**:
  - Implemented series CRUD operations with user isolation and project ownership validation.
  - Modeled `RecurrenceEditScope` enum (`THIS_OCCURRENCE`, `THIS_AND_FUTURE`, `SERIES`).
  - `SERIES`: Updates master series definition and syncs open, non-overridden future occurrences.
  - `THIS_OCCURRENCE`: Updates single task occurrence instance and records an `OVERRIDDEN` exception without affecting series aggregate.
  - `THIS_AND_FUTURE`: Truncates existing series `endDate` before edit date and initializes a new `RecurringTaskSeries` starting on edit date.
  - `skipOccurrence`: Saves `SKIPPED` exception and deletes uncompleted task instance if generated.
  - `deleteSeries`: Soft-deletes recurring series and deletes uncompleted occurrences.

- **REST Controller & DTO Contracts (`tech.buildwithpartha.lifeos.task.api.RecurringTaskSeriesController`)**:
  - `POST /tasks/recurring-series` — Create series & generate initial occurrences.
  - `GET /tasks/recurring-series` — List active series for user.
  - `GET /tasks/recurring-series/{id}` — Get series details.
  - `PUT /tasks/recurring-series/{id}` — Update series with scope selection.
  - `DELETE /tasks/recurring-series/{id}` — Delete series and uncompleted occurrences.
  - `POST /tasks/recurring-series/{id}/skip` — Skip occurrence date with reason.
  - `GET /tasks/recurring-series/{id}/exceptions` — List exception records.
  - Integrated `ProductActivityPort` emitting content-free activity events (`TASK_CREATED`, `TASK_UPDATED`, `TASK_DELETED`).

- **Test & Quality Verification**:
  - Unit tests: `RecurrenceOccurrenceEngineTests`, `RecurrenceGenerationServiceTests`, `RecurrenceGenerationJobTests`, `RecurringTaskSeriesServiceTests`.
  - Controller integration tests: `RecurringTaskSeriesControllerTests`.
  - Quality suite: `./gradlew check` passed 100% (Spotless formatting, Checkstyle rules, ArchUnit package boundary rules, JaCoCo branch coverage >= 80%, all unit & integration tests).
