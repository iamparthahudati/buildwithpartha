  - Verified skip-to-content navigation (`#lifeos-main-content`) with keyboard focus activation.
  - Verified 320px reflow (WCAG 1.4.10) with zero horizontal document scroll overflow (`scrollWidth <= innerWidth`).

  - 100% test pass across all 88 scenarios (37 desktop + 37 mobile accessibility tests + 14 core journeys).

- **Accessibility Remediations**:
  - Remediated active task summary metric preset label contrast by binding `.lifeos-task-summary-metrics__item--active .lifeos-metric__label` to `--lifeos-color-on-primary-soft` (`#1d3fcc`), elevating contrast from 4.44:1 to 5.5:1.
  - Remediated circular progress ring center value background by setting explicit `background: var(--lifeos-color-surface)` on `.lifeos-progress-ring__value`, providing unambiguous 15.3:1 contrast against `--lifeos-color-text`.
  - Remediated task project links across `TaskCard.tsx`, `TaskRow.tsx`, and `TasksScreen.tsx` by ensuring a fallback accessible name (`task.project.name || "Project"`) to prevent empty anchor tags.
  - Added `/sprints` and `/sprints/:id` route handlers to the in-memory mock API fixture (`mockApi.ts`).
