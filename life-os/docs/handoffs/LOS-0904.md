## Completed behavior
- Built `TimeBlockForm` React component in `src/features/time-blocks/components/TimeBlockForm.tsx` supporting:
  - Form modes for both `"create"` and `"edit"`.
  - Fields: Title (required), Category (with color/icon resolution), Status (`SCHEDULED`, `IN_PROGRESS`, `COMPLETED`, `CANCELLED`), Date (`DateInput`), Start & End times (`TimeInput`), Linked Project (`Select`), Linked Task (`Select`), Timezone (`TextInput`), and Notes (`Textarea`).
