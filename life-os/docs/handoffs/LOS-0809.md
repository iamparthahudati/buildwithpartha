## Completed behavior

- Added TaskRow and TaskCard as separate responsive renderers over one typed Task list projection, ready for the mocked Tasks screen in LOS-0812.
- Both components expose controlled selection and render Task title/deep link, optional Project context, canonical status and Product priority, UTC due instant formatted in the confirmed user timezone, bounded progress, comment count, and MIT designation.
- Supports the required overdue, blocked, done, archived, and loading states. Overdue is suppressed for terminal and archived Tasks; blocked rows/cards include a textual blocker count; done titles are visibly completed without changing their underlying Task status.
- Added one shared accessible action menu that only exposes lifecycle-valid actions: focus is unavailable while blocked or terminal, MIT/done actions are unavailable when terminal, terminal Tasks may reopen, and archived Tasks expose only restore/delete callbacks supplied by the caller.
- Added development catalog specimens for selected active MIT, overdue/blocked, done, archived, and loading row/card states.
- Corrected the responsive row grid after live 320px testing showed absent selection/action controls could shift content into the wrong columns. Fixed layout slots now stay stable with or without optional controls.
