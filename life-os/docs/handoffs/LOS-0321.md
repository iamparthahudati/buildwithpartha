## LOS-0321 — ProgressBar

The bar reports a real measurement or it reports nothing. `indeterminate` carries **no `aria-valuenow`**, and that omission is the whole point: reporting zero would tell a screen-reader user the work has not started, which is a different thing from not knowing how far along it is.

`readProgress` (`components/ui/progress.ts`) is the single reading both progress components share, and it holds the one decision worth arguing about — rounding that cannot lie in either direction. Ordinary rounding turns 99.6% into "100%" beside a list that still has work in it, and 0.4% into "0%" beside a project that has genuinely started. Only a true zero reads as 0% and only a true one reads as 100%; everything between is held inside 1–99.

A maximum of zero, a negative maximum or a `NaN` produces an empty reading rather than `NaN` or a full bar. That case is real: a metric whose denominator has not loaded yet would otherwise render as complete.

`label` is required, and hiding it hides the shown value with it. "40%" of what? A percentage with no metric beside it cannot be read, and the tone guide already forbids it.

## LOS-0322 — ProgressRing

The same reading drawn as a dial, sharing `readProgress` rather than repeating the arithmetic, so a ring and a bar showing the same metric can never disagree.

The arc is one conic gradient driven by one custom property, turned into a ring by a radial mask. There is no SVG geometry to compute in JavaScript and nothing to recalculate on resize. Zero and full are special-cased in CSS: at zero the arc must be genuinely absent rather than a hairline that reads as "just started", and at full it must close without a seam.

The centre percentage is `aria-hidden` — it repeats what the progressbar role already announces.

## LOS-0323 — Spinner

A spinner says "something is happening" and nothing else. It cannot say what is loading, how long it will take, or what to do if it never finishes. `label` is therefore required, which makes an unlabelled busy indicator a type error rather than something to catch in review, and the label is real text **inside** the `role="status"` region rather than an `aria-label` on an empty shape — a live region announces the text it contains.

## LOS-0324 — Skeleton

A skeleton exists to stop the page moving: it reserves the space the real content will occupy, so nothing reflows under the user's pointer the moment the data arrives. That is the harm a spinner in a list actually does.

Every skeleton is hidden from assistive technology. Announcing a dozen placeholder shapes tells a screen-reader user nothing and buries the one message that matters; the waiting state is announced once, by the region's own status text.

The sheen travels across the shape rather than the shape pulsing — a pulse changes the element's own contrast, which reads as something arriving. `SkeletonTable` renders plain boxes rather than an empty `<table>`, which would be markup assistive technology tries to describe.

## LOS-0325 — Divider

Silent by default. Most rules on a page are decoration: the grouping they suggest is already carried by headings, landmarks and list structure, so announcing "separator" on every one of them adds noise without adding meaning. `semantic` adds the role when the line itself carries the structure, and a labelled break ("Earlier") takes its name from `aria-label` with the visible text hidden, because `separator` does not take its name from its content.

Horizontal semantic dividers render as `<hr>`, which already has the role; only vertical ones need to declare it.

## Known limitations or follow-ups

- `Button` still draws its own spinner rather than composing `Spinner` (LOS-0306 predates it). Queued for LOS-0331 alongside the `Field` migration.
- Reduced-motion and forced-colors behaviour is asserted by reading the stylesheets, not by rendering under those preferences; jsdom has no media-query engine. Real-browser confirmation belongs to LOS-0332.
- `ProgressRing` relies on CSS `mask`, which is supported across the declared browser target. In forced-colors mode the mask is dropped and the dial falls back to a bordered circle, with the percentage in the middle carrying the value.
- `SkeletonTable` takes a fixed column count; a responsive column count belongs to whichever composed table needs it.
