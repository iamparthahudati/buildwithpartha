## Overview
This ticket implements the CRUD notes backend APIs (LOS-1201) and completes the frontend notes list and editor components (LOS-1202) following LifeOS standards.

## Component Structure & Files

### Backend (LOS-1201)
- **Controller**: [NoteController.java](file:///Users/parthahudati/Workspace/Website/buildwithpartha/life-os/apps/api/src/main/java/tech/buildwithpartha/lifeos/note/api/NoteController.java) mapping GET, POST, PUT, DELETE endpoints for Note management.
