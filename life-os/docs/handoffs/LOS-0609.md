## Completed behavior

Built the isolated Today plan feature component without moving later screen-composition or API-integration work into this ticket.

- `TodayPlan` presents the MIT region before the deliberately limited list of Tasks and gives both regions independent loading, first-use, error and ready state contracts. A Task-list failure leaves a usable MIT visible, and an MIT failure leaves today's Tasks visible.
- `TodayMitCard` renders the selected Task's canonical priority/status, optional Project context, localized due label and expanded accessible meaning for MIT. It provides Start focus, Mark done, Open task and Change MIT paths. Its first-use state offers Choose focus and Add task; its error state offers isolated retry and safe navigation to Tasks.
- `TodayTaskList` composes the shared generic `DataTable` on wide screens and supplies a domain-aware Task card below 768px. Rows/cards show Task, Project or honest projectless context, canonical priority/status, MIT designation and Set as MIT, Mark done and Start focus actions.
- Mutation state remains caller-controlled. The active pending button stays focusable and busy while competing mutations are disabled; callers may explicitly disable individual actions, such as Start focus for a blocked Task.
- Ready, first-use and partial-error catalog specimens use approved neutral LifeOS fixtures. The ready specimen keeps the MIT and list projection consistent when the user changes the MIT or marks it done.
