## Completed behavior

- Built reusable Spring MVC idempotency infrastructure using `Idempotency-Key` header and `@Idempotent(operation = "...")` annotation:
  - `IdempotencyRecord` entity and Flyway migration `V33__idempotency_schema.sql` (and test `schema.sql`) for scoped storage by `(user_id, idempotency_key)`.
  - `IdempotencyFilter` intercepting annotated controller methods, caching response payloads/status, replaying identical requests within retention window (24h default), and enforcing 409 `IDEMPOTENCY_KEY_REUSED` when the key is reused across different operations.
  - `IdempotencyCleanupJob` scheduled background job for purging expired idempotency keys.
  - Annotated core create endpoints (`CREATE_TASK`, `CREATE_PROJECT`, `CREATE_NOTE`, `CREATE_GOAL`, `CREATE_BRAIN_DUMP`).
- Added full unit and integration test coverage (`IdempotencyIntegrationTests`, `IdempotencyCleanupJobTests`).
