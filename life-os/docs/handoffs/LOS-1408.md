# LOS-1408 Handoff: Generic Idempotency Infrastructure

- Status: Done
- Branch: `feature/LOS-1408-add-idempotency-infrastructure`
- Date: 2026-09-05

## Completed Behavior

- Built reusable Spring MVC idempotency infrastructure using `Idempotency-Key` header (8-64 safe ASCII characters) and `@Idempotent(operation = "...")` annotation:
  - `IdempotencyRecord` entity and Flyway migration `V33__idempotency_schema.sql` (and H2 test `schema.sql`) for scoped persistence by `(user_id, operation_type, idempotency_key)`.
  - Retention window default of 7 days (`DEFAULT_RETENTION = Duration.ofDays(7)`).
  - `IdempotencyAspect` intercepting annotated controller methods, transparently caching/replaying response payloads and HTTP status codes, and raising 409 `IDEMPOTENCY_KEY_REUSED` (`IdempotencyKeyReusedException`) when a key is reused across different operation types.
  - Concurrent request protection: atomic database key lock handling concurrent requests using `ConcurrencyConflictException` mapped to 409 `CONCURRENT_REQUEST`.
  - `@Scheduled` background job `IdempotencyCleanupJob` purging expired records daily at 03:00 UTC.
  - Annotated core create endpoints (`CREATE_TASK`, `CREATE_PROJECT`, `CREATE_NOTE`, `CREATE_GOAL`, `CREATE_BRAIN_DUMP_ITEM`).
- Fully unit tested and integration tested:
  - `IdempotencyKeyTests`, `IdempotencyServiceTests`, `IdempotencyAspectTests`, `IdempotencyCleanupJobTests`, `IdempotencyRecordEntityTests`, and `IdempotencyIntegrationTests`.
