## Completed behavior

Added the Flyway migration that models the identity domain: `users`, `credentials`, `user_sessions`, `email_verification_tokens`, `password_reset_tokens`, and `terms_acceptances`. All token/session tables store only a hash of the raw secret (`token_hash` / session `token_hash`), never the raw value, matching `06-SECURITY.md`. Every child table cascades on user deletion, `users.email`/`email_normalized` are uniquely constrained, `account_status` and `week_start` are check-constrained, and each token/session table carries a partial index (`WHERE revoked_at/consumed_at IS NULL`) sized for its expiry-cleanup query.
