## Completed behavior

- **Authored Cloudflare Specification (`life-os/docs/40-CLOUDFLARE-DNS-PROXY-AND-TLS.md`)**:
  - Established canonical specification for Cloudflare DNS, proxied status, SSL/TLS encryption, cache rules, Web Application Firewall (WAF), rate limiting, and origin host firewall restriction.
  - Specified DNS records for apex `buildwithpartha.tech`, alias `www.buildwithpartha.tech`, and staging subdomain `staging.buildwithpartha.tech` with Orange Cloud proxy status enabled.
  - Defined SSL/TLS encryption mode standard `Full (strict)` with 15-year Cloudflare Origin CA certificate installed on origin Caddy server (`/etc/life-os/certs/origin.crt` & `origin.key`) to eliminate Man-In-The-Middle risk.
  - Specified Authenticated Origin Pulls (AOP) mTLS certificate validation on Caddy proxy.
  - Established Cache Bypass Policy Matrix forcing edge cache bypass on dynamic API paths (`/life-os/api/*`, `/api/*`), private SPA routes (`/life-os/app/*`), staging domain (`staging.buildwithpartha.tech`), and requests carrying `Authorization` headers or session cookies (`lifeos_session`, `lifeos_staging_session`, `JSESSIONID`).
  - Defined static asset caching rules (`/life-os/assets/*`) with 1-year browser TTL and 30-day edge TTL.
  - Specified WAF rate limiting rules enforcing max **10 requests per minute** on authentication endpoints (`/life-os/api/v1/auth/*`) and max **120 requests per minute** on general REST APIs (`/life-os/api/*`).
  - Established direct origin bypass prevention strategy restricting VPS inbound ports 80/443 strictly to Cloudflare published IPv4 and IPv6 subnets via UFW firewall.

- **Created Cloudflare Declarative Ruleset (`life-os/infra/cloudflare/cloudflare-ruleset.json`)**:
  - Created declarative JSON schema declaring zone settings, DNS records, SSL/TLS `full_strict` mode, origin CA paths, cache rules, rate limiting thresholds, and origin UFW parameters.

- **Created Origin Firewall Restriction Script (`life-os/infra/cloudflare/configure-cloudflare-origin-firewall.sh`)**:
  - Created executable shell script to parse official Cloudflare IPv4 (`https://www.cloudflare.com/ips-v4`) and IPv6 (`https://www.cloudflare.com/ips-v6`) address ranges and apply Hostinger VPS UFW firewall rules (`ufw allow from <ip> to any port 80,443 proto tcp`). Supports `--dry-run` and `--force` execution modes.
