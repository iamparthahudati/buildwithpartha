## Completed behavior

Implemented the authenticated Today dashboard foundation endpoint (`GET /today`), timezone resolution, provider composition shell, zero-safe default domain providers, provider failure isolation, and explicit cache headers.

- **Authenticated timezone & profile resolution**: Created `UserTimeZoneProvider` in `tech.buildwithpartha.lifeos.common.user` and implemented `UserTimeZoneAdapter` in `user.application` querying `UserProfileService`. Resolves the authenticated user's preferred IANA timezone (falling back safely to `"UTC"` if unspecified or invalid) and calculates the user's local date for the current instant.
- **Domain isolation**: Domain boundary rules (`PackageBoundaryRules.domainIsolation()`) are fully preserved by using `UserTimeZoneProvider` in `common.user`, ensuring the `report` domain never directly imports or depends on the `user` domain.
- **Provider composition shell**: Created 13 modular widget provider interfaces (`MitWidgetProvider`, `TasksWidgetProvider`, etc.) in `report.application.provider` and 13 zero-safe default Spring `@Component` implementations in `report.infrastructure.provider` returning typed `Widget.empty()` states for unimplemented domains.
- **Provider failure isolation**: `TodayService` executes each provider within an isolated try-catch (`safeFetch`). If a provider throws an exception, only that widget transitions to `WidgetStatus.ERROR` while the remaining 12 widgets continue returning successful data.
- **Cache policy**: `TodayController` returns HTTP 200 OK with `Cache-Control: private, no-store, max-age=0, must-revalidate` response headers for privacy and account isolation.
- **Architecture & test suite**: Added `TodayQueryResult` in `report.application` and mapped cleanly to `TodayResponse` in `report.api` to uphold `PackageBoundaryRules.layerDirection()`. Added unit and integration tests (`TodayServiceTests`, `UserTimeZoneAdapterTests`, `TodayControllerTests`).
