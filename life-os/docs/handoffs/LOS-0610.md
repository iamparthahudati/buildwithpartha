## Completed behavior

Built the reusable Today schedule component and its individual Time Block row.

- `TodaySchedule` accepts one discriminated loading/empty/error/ready state. A zero-row ready payload safely renders the same honest first-use state rather than an empty list.
- Ready Time Blocks are ordered by canonical local start time and expose current, next, upcoming, completed and conflict states as visible labels; conflict descriptions remain readable text and never depend on color alone.
- Each row formats time-only values using the confirmed locale without attaching the browser timezone, links its title/project to the canonical record, and exposes an explicit Open action.
- Current and next Time Blocks offer Start focus. A pending start remains focusable and announced busy, while other starts are disabled to prevent parallel requests; callers may also provide the reason starts are unavailable.
- Add time block remains available from the section header and first-use state. Loading uses one announced busy region with row-sized placeholders. An isolated error preserves the rest of Today and provides Retry plus Open Time Blocks.
- Rows render time/content/actions in three columns on desktop and stack in logical reading order below 768px. The section header also stacks at narrow widths so its action cannot overflow.
- Development catalog specimens cover ready/conflict, first-use, loading and isolated-error states.
