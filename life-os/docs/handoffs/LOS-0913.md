## Completed behavior

- Added authenticated Focus Session start, owned-session read, active-session recovery, pause, resume, start-break, resume-focus, complete, cancel, and private interruption endpoints under `/focus-sessions`.
- Made the injected UTC server clock authoritative. Each representation includes `serverNow`, canonical clock anchors, and focus/break totals calculated at that response instant so refresh, sleep, and background recovery do not depend on the browser clock.
- Required an 8–64 character `Idempotency-Key` for every write. Account-scoped operation records replay the same session result, reject reuse across commands/sessions, and expire after seven days.
- Serialized Focus Session writes on the owning Account row, retained optimistic session versions, and kept the database's one-active-session constraint. Concurrent starts in separate request threads prove that exactly one succeeds.
- Added safe lifecycle conflicts for an existing active session, invalid state transitions, stale versions, and reused idempotency keys without exposing private content or raw exception details.
- Validated optional Task and Time Block context through domain-neutral ports. A Time Block can infer its linked Task; mismatched, terminal, deleted, archived, missing, and cross-user context is rejected generically.
- Starting focus marks a linked Scheduled Time Block In progress. Completing focus marks a non-terminal linked block Completed and records confirmed whole focus minutes on the linked Task exactly once without completing that Task. Cancelling does not add Task time and returns an In-progress linked block to Scheduled.
- Kept cancelled session focus/break duration as truthful history and kept interruption notes private, normalized plain text.
