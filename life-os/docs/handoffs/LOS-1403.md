## Completed behavior

Implemented persistent background job framework (`tech.buildwithpartha.lifeos.job` and `common.job`) conforming to `02-ARCHITECTURE.md`, `06-SECURITY.md`, `31-PRIVACY-DATA-LIFECYCLE.md`, and `docs/backlog/EPIC-14-BACKEND-OPERATIONS.md`:

- **Database Migration (`V5__background_jobs_schema.sql`)**:
  - `public.background_jobs` table with UUID primary key, optional `user_id` foreign key cascade-deleting with user, `job_kind` check constraint (`DATA_EXPORT`, `ACCOUNT_DELETION`), status check constraint (`PENDING`, `RUNNING`, `SUCCEEDED`, `FAILED`, `DEAD_LETTERED`), and attempt tracking.
  - Partial index `ix_background_jobs_pending` on `next_attempt_at WHERE status = 'PENDING'` for high-efficiency polling.
  - Partial index `ix_background_jobs_cleanup` on `updated_at WHERE status IN ('SUCCEEDED', 'DEAD_LETTERED')` for R1 retention purges.
- **Cross-Domain Port (`tech.buildwithpartha.lifeos.common.job`)**:
  - `BackgroundJobPort`: Cross-domain transactional enqueue port that joins the caller's transaction (`REQUIRED` propagation).
  - `BackgroundJobKind`: Enum defining registered job types (`DATA_EXPORT`, `ACCOUNT_DELETION`).
- **Domain Layer (`tech.buildwithpartha.lifeos.job.domain`)**:
  - `BackgroundJob`: Immutable domain aggregate enforcing state machine (`PENDING -> RUNNING -> SUCCEEDED / PENDING / DEAD_LETTERED`), erasing JSON payload on terminal states (R1 privacy requirement).
  - `BackgroundJobStatus`: Enum covering job lifecycle.
  - `JobRetryPolicy`: Exponential backoff with configurable base delay, max delay, and max attempts (default 10).
  - `BackgroundJobRepository`: Port defining save, findById, findDuePending (with limit), and deleteTerminalOlderThan.
- **Application Layer (`tech.buildwithpartha.lifeos.job.application`)**:
  - `BackgroundJobEnqueueService`: `@Transactional` enqueue service saving new PENDING jobs.
  - `BackgroundJobWorker`: `@Scheduled(fixedDelay = 30_000)` poller executing claimed jobs via registered handlers, recording successes or failures with retry backoff, and redacting sensitive log details.
  - `JobHandler` & `@JobHandlerFor`: Handler strategy interface and annotation for extensible job handlers.
  - `JobHandlerRegistry`: Discovers and validates all handlers at startup.
  - `JobCleanupJob`: `@Scheduled(cron = "0 45 3 * * *")` daily purge for terminal rows older than 7 days.
- **Infrastructure Layer (`tech.buildwithpartha.lifeos.job.infrastructure`)**:
  - `BackgroundJobEntity`: JPA entity mapping to `public.background_jobs`.
  - `BackgroundJobJpaRepository`: Spring Data JPA repository with custom JPQL queries.
  - `JpaBackgroundJobRepository`: Implements `BackgroundJobRepository`.
  - `BackgroundJobPortAdapter`: Implements `common.job.BackgroundJobPort`.
- **Architecture & Rules**:
  - Updated `PackageBoundaryRules.java` to approve `"job"` domain package.
  - Updated test `schema.sql` for H2 test validation.
