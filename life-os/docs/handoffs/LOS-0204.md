## Completed behavior

Added a standalone local PostgreSQL 18.4 Compose service for LifeOS. It binds only to loopback port `55432`, avoiding the existing PostgreSQL service on host port `5432`, and stores disposable data in the explicitly named `life-os-local-postgres-data` volume on an internal LifeOS-only network.

Container initialization keeps the PostgreSQL bootstrap administrator separate from `lifeos_local_app`. The API role is created without superuser, database-creation, role-creation or replication privileges and receives only the current database/schema access needed for the upcoming Flyway baseline.

The local React preview had stopped before this ticket began. It was restarted at `http://127.0.0.1:5173/life-os/`, verified responsive and left running for the owner.
