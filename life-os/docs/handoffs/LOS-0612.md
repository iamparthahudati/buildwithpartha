## Completed behavior

Built the Today active Projects and Next up components as independent, composable feature surfaces for LOS-0614.

- `ActiveProjectRow` presents one active Project as a semantic Project link with an explicit Active badge and canonical completed/total task progress. A Project without a meaningful task denominator says `No tasks yet.` instead of inventing `0%`; inconsistent counts are clamped before they are announced.
- `TodayActiveProjects` caps the Today projection to three rows by default, keeps the full collection behind `View all`, and displays its caller-supplied canonical source. Loading reserves three stable rows, first use offers `Add project` without sample data, and a load error remains an isolated retryable region.
- `TodayNextUp` returns no markup for an active-focus state. Its visible states require either no focus selected or a completed focus and explain that availability in text.
- A ready Next up Task shows Project context, canonical Product priority, optional timing context, and an optional Start focus action with disabled and pending behavior.
- Next up always names the caller-supplied canonical Task source and deterministic ranking rule. A ready Task additionally requires the recorded facts that ranked it first under that rule. No component copy describes the result as AI-generated or inferred.
- Both widgets are responsive down to narrow mobile widths, use real links/buttons, preserve logical reading order, and expose labelled loading/error regions.
- Development catalog specimens cover ready and first-use active Projects plus both eligible Next up reasons.
