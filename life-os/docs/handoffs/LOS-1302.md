## Completed behavior

- **Global CommandPalette Overlay (`GlobalCommandPalette.tsx`)**:
  - Wired live global search query fetching (`GET /life-os/api/v1/search?q=...&size=5`) into `CommandPalette` component.
  - Global `Cmd/Ctrl+K` keyboard shortcut and TopBar search click trigger open the `CommandPalette`.
  - Empty query state displays recent search history and navigation shortcuts (`Quick add task`, `Go to Today`, `Go to Tasks`, `Go to Projects`, `Go to Notes`, `Go to Settings`).
  - Active query state displays live grouped search results across Projects, Tasks, Notes, Brain Dump items, Goals, and Habits with icons, title/snippet highlights, and direct deep link navigation.
  - Selecting "View all results for '{query}'" or pressing Enter when no item is highlighted navigates directly to `/life-os/app/search?q={query}`.

- **Full Global Search Screen & Route (`/life-os/app/search`)**:
  - Built `SearchScreen` and `SearchRoute` at canonical URL route `/life-os/app/search`.
  - Driven by URL search parameters (`q` query string, `type` entity filter, `page` pagination).
  - Supports filter pill bar for All, Projects, Tasks, Notes, Brain Dump, Goals, and Habits with live entity hit counts.
  - Grouped view when searching across all types and flat paginated list view when entity filter or pagination is active.
  - Safe HTML highlight rendering (`renderSafeHighlightedText`) parses backend `<mark>` tags without using `dangerouslySetInnerHTML`.
  - Full loading spinner state, empty prompt state, zero-results state, and offline warning indicator (`InlineMessage`).
  - Full accessibility coverage (`expectNoAccessibilityViolations` passing 100% `axe` audit).

- **Query Privacy & Recent Searches (`useRecentSearches.ts`)**:
  - Scoped per user in `localStorage` under `lifeos_recent_searches_{userId}`, capped at 10 items, with clear recent searches capability.
  - Search queries and body content are never logged to console or external trackers.
