## Completed behavior

Implemented the Brain Dump API (LOS-1204) — a quick capture inbox that allows users to capture thoughts as Brain Dump items and later triage them by converting them idempotently into Tasks, Notes, Projects, or Goals. The Today widget now reports the live unprocessed item count from the database.

Specifically:

- **Capture**: `POST /brain-dump-items` creates a new `UNPROCESSED` item, returning a `201 Created` with a `Location` header.
- **Get**: `GET /brain-dump-items/{id}` retrieves a single user-owned item.
- **List**: `GET /brain-dump-items` queries items with optional filters (`q`, `status`, `archived`), pagination, and sort.
- **Update content**: `PUT /brain-dump-items/{id}` updates item text (optimistic concurrency via `version`).
- **Defer**: `POST /brain-dump-items/{id}/defer` transitions an item to `DEFERRED`.
- **Archive / Restore**: `POST /brain-dump-items/{id}/archive` and `/restore` lifecycle operations.
- **Delete**: `DELETE /brain-dump-items/{id}` permanent deletion.
- **Idempotent conversion**:
  - `POST /brain-dump-items/{id}/convert/task` → creates a Task and marks item `CONVERTED`
  - `POST /brain-dump-items/{id}/convert/note` → creates a Note
  - `POST /brain-dump-items/{id}/convert/project` → creates a Project
  - `POST /brain-dump-items/{id}/convert/goal` → creates a Goal
  - If already converted, returns the existing item immediately (no duplicate creations).
- **Today widget**: `DefaultBrainDumpWidgetProvider` now queries the database via `BrainDumpCountProvider` and returns the actual unprocessed count.
