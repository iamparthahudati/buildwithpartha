## Completed behavior

Implemented self-service account data export request, asynchronous processing, and secure short-lived private download lifecycle conforming to `02-ARCHITECTURE.md`, `05-API-CONVENTIONS.md`, `06-SECURITY.md`, `31-PRIVACY-DATA-LIFECYCLE.md`, and `docs/backlog/EPIC-05-IDENTITY.md`:

- **Domain-Neutral Architecture & Contributors**:
  - `tech.buildwithpartha.lifeos.common.export.UserDataExportContributor`: Inward domain-neutral interface implemented by domain aggregates to contribute portable machine-readable files into user data archives without cross-domain leakage.
  - `AccountExportContributor` (`auth` domain): Serializes account identity, email, verification status, and localization context to `account.json` (strictly excludes password hashes and session secrets per privacy posture).
  - `TermsExportContributor` (`auth` domain): Serializes versioned terms and privacy acknowledgment history to `terms.json`.
  - `UserPreferencesExportContributor` (`user` domain): Serializes schedule and focus preferences to `preferences.json`.
- **Export Packaging & Execution**:
  - `ExportArchiveBuilder` (`export.application`): Collects sections from all registered contributors, generates `manifest.json` and human-readable `README.md`, and compresses into a UTF-8 ZIP archive in memory.
  - `DataExportJobHandler` (`export.application`): Background job worker annotated with `@JobHandlerFor(BackgroundJobKind.DATA_EXPORT)` that builds archive, persists via `ExportFilePort`, sends completion notification mail via `TransactionalMailPort`, and logs security audit events.
  - `DataExportService` (`export.application`): Coordinates quota validation (`MAX_ACTIVE_EXPORTS_PER_USER = 3`), export initialization, job enqueueing, and retrieval.
- **Authenticated REST Endpoints (`tech.buildwithpartha.lifeos.export.api.DataExportController`)**:
  - `POST /auth/export`: Enqueues an asynchronous background job, subject to active quota check. Returns `202 Accepted` with initialized metadata.
  - `GET /auth/export/status`: Returns current active and past export records for authenticated user.
  - `GET /auth/export/download?token=...`: Validates user ownership and short-lived download token, and streams binary `application/zip` with `Content-Disposition: attachment; filename="lifeos-export-..."` and cache prevention headers.
- **Export Schema Documentation**:
  - `docs/schemas/data-export.schema.json` documenting manifest schema and archive file expectations.
