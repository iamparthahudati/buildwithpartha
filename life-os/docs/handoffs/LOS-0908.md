## Completed behavior
- Integrated the composed Time Blocks screen (`TimeBlocksScreen`, LOS-0907) with authenticated backend REST APIs (`TimeBlockController`, LOS-0902):
  - Created typed REST API client module `src/features/time-blocks/api/timeBlocksApi.ts` supporting `queryTimeBlocks`, `getTimeBlock`, `createTimeBlock`, `updateTimeBlock`, `moveTimeBlock`, `resizeTimeBlock`, `changeTimeBlockStatus`, `completeTimeBlock`, `duplicateTimeBlock`, `deleteTimeBlock`, `checkTimeBlockOverlap`, and bidirectional `Instant` <-> `LocalDate`/`LocalTime` conversions.
  - Created TanStack Query hook module `src/features/time-blocks/hooks/useTimeBlocks.ts` for time block listing, detail, and mutation hooks (`useCreateTimeBlock`, `useUpdateTimeBlock`, `useMoveTimeBlock`, `useResizeTimeBlock`, `useChangeTimeBlockStatus`, `useCompleteTimeBlock`, `useDuplicateTimeBlock`, `useDeleteTimeBlock`, `useCheckTimeBlockOverlap`).
  - Configured precise cache invalidations on all time block mutations: invalidates `time-blocks` (`TIME_BLOCKS_QUERY_KEY`), `today` (`TODAY_QUERY_KEY`), and `calendar` (`CALENDAR_QUERY_KEY`) query keys.
  - Created integrated container route `src/routes/TimeBlocksRoute.tsx` reading `date` and `view` URL query parameters, binding user authenticated timezone/locale, populating project/task selection options from `useProjects`/`useTasks`, handling optimistic/async CRUD operations, and triggering user-facing success toasts.
  - Mounted `<TimeBlocksRoute />` at `/life-os/app/time-blocks` in `src/app/AppRouter.tsx` and re-exported in `src/routes/index.ts`.
  - Re-exported all API functions, DTOs, and hooks in `src/features/time-blocks/index.ts`.
