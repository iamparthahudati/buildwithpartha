## Completed behavior

- **Implemented Full Attachment Backend domain, application, infrastructure, and REST API (`tech.buildwithpartha.lifeos.attachment`)**:
  - Implemented `Attachment` domain aggregate, status enum (`PENDING_SCAN`, `CLEAN`, `QUARANTINED`, `DELETED`), and quota limits (`AttachmentQuotas`: 25 MB max per file, 2 GB total per account, max 20 attachments per entity).
  - Implemented `AttachmentMimeValidator` with strict MIME allowlists, magic-byte binary header inspection, filename sanitization, path traversal prevention, and forbidden extension detection.
  - Implemented `S3AttachmentStorageAdapter` for object storage and `ClamAvScannerAdapter` for anti-malware scanning.
  - Implemented `AttachmentScanJobHandler` registered for `BackgroundJobKind.ATTACHMENT_SCAN`, scanning uploaded binaries via ClamAV and updating attachment status to `CLEAN` or `QUARANTINED`.
  - Implemented `AttachmentDownloadService` streaming clean files with security headers (`Content-Disposition: attachment`, `X-Content-Type-Options: nosniff`, `Content-Security-Policy: default-src 'none'`) and recording `ATTACHMENT_DOWNLOADED` security audit events with `AuditOutcome.SUCCEEDED` / `SUCCEEDED` / `DENIED`.
  - Implemented REST controller `AttachmentController` (`/attachments`) controlled by feature flag `lifeos.features.attachments.enabled`.
- **Database Schema Migration (`V32__attachments_schema.sql`)**:
  - Created `public.attachments` schema with indices on `(entity_type, entity_id)`, `user_id`, and `status`.
  - Updated `ck_security_audit_event_type` check constraint to include `ATTACHMENT_UPLOADED`, `ATTACHMENT_DOWNLOADED`, `ATTACHMENT_QUARANTINED`.
- **Package Invariants & System Integrity**:
  - Registered `attachment` package in `PackageBoundaryRules.java` and `STRUCTURE.md`.
  - Passed full quality gate (`./gradlew check --no-daemon`) with 1166 passing unit/integration tests, 0 failures, Spotless, Checkstyle, ArchUnit, and JaCoCo line & branch coverage (>= 80%).
