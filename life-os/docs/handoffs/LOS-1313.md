## Completed behavior

- **Created Offline Mutation Queue Domain Module (`src/features/offline-mutation-queue`)**:
  - Implemented `model/mutationQueue.ts` defining allowed creation mutation types (`CREATE_TASK`, `CREATE_NOTE`, `CREATE_BRAIN_DUMP_ITEM`), stable client UUID generation (`generateClientUuid`), content-free 8–64 character idempotency keys (`generateIdempotencyKey`), 7-day default TTL calculation, and expiry checks (`isMutationExpired`). Disallowed offline mutation types are rejected on enqueue.
  - Implemented `model/queueStorage.ts` for session-scoped, user-bound (`lifeos.queue.<userId>.<id>`) storage persistence with payload obfuscation/encryption (`encryptQueuePayload` / `decryptQueuePayload`) using a user-bound salt (`${userId}-lifeos-queue-salt`). Automatically prunes expired mutations and provides `clearUserMutationQueue(userId)` and `clearAllMutationQueues()`.
  - Implemented `api/queueReplayer.ts` for sequential replay of pending queued mutations upon network reconnection. Attaches content-free `Idempotency-Key` headers to create requests, handles lost-response recovery safely, removes succeeded items, flags HTTP 409 concurrency conflicts (`status = "conflict"`), and increments attempt counts on retryable errors.
  - Implemented `hooks/useOfflineMutationQueue.ts` subscribing to network reconnection events (`window.addEventListener("online")`), triggering auto-replay, and providing methods (`enqueueMutation`, `retryMutation`, `removeMutation`, `clearQueue`, `replayQueue`).
  - Implemented `components/OfflineQueueBadge.tsx` displaying the canonical UX badge `Queued — will sync when online` and pending counts with live-region status announcements (`role="status"`).
  - Exposed module through public entrypoint `index.ts`.
- **Integrated Auth Session Logout Cleanup (`AuthSessionProvider.tsx`)**:
  - Updated `clearSession()` and account switching in `setSession()` to purge all user-scoped queued mutations (`clearUserMutationQueue` / `clearAllMutationQueues`).
  - Added unit test assertion in `AuthSessionProvider.test.tsx` verifying offline mutation queue purge on session clear.
- **Integrated Offline Creation Queueing with Quick Add Dialog (`QuickAddDialog.tsx`)**:
  - Wired offline task and brain-dump creation to `enqueueMutation` and triggered `Queued — will sync when online` info toasts when offline.
- **Quality & Verification**:
  - Passed quality gate (`npm run verify:quality` in `apps/web`) with zero ESLint/TypeScript/boundary errors and zero design token violations.
  - Passed unit test suite for `@features/offline-mutation-queue` and full web unit test suite (`npm run test:unit`, 338 files / 2,493 tests passing).
  - Passed documentation link validation (`node life-os/scripts/validate-docs.mjs`).
