## Completed behavior

- Replaced Quick Add's simulated Note, Brain Dump, and Habit submissions with the canonical feature mutations. Habit choices come from the signed-in user's active Habits, and fields remain available for retry when a confirmed write fails.
- Reports `saved` only after the server confirms a write and `queued` only after an offline Brain Dump capture is persisted to the existing per-user browser queue. Note capture is explicitly unavailable offline because Notes have no durable offline queue.
- Centralized the Brain Dump capture queue in the authenticated shell so Quick Add, Today, and the Brain Dump screen share one auto-flusher and one pending-item source instead of competing queue instances.
- Added an owner-scoped backend Today Habit projection. Each active Habit uses its own IANA timezone and current local date, current completion count, pause state, target/cadence, and the authoritative cadence-aware streak calculator.
- Added a responsive, accessible Today Habits widget with loading, empty, error, paused, ready, pending, and mutation-error states. Increment/decrement actions use the existing absolute set/remove service and the exact projected Habit local date.
- Routed confirmed Brain Dump capture, lifecycle, conversion, and queue-flush changes to the Brain Dump, Today, and Activity query families. Content-only edits invalidate only Brain Dump; Habit entry mutations retain their existing Habit, Today, and Activity invalidation.
