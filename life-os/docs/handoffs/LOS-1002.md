## Completed behavior

- Built the complete set of Sprint management components in `apps/web/src/features/sprints/components/`:
  - `SprintCard.tsx` (`sprint-card.css`, `SprintCard.test.tsx`): Card displaying Sprint status badges (`Planned`, `Active`, `Completed`, `Cancelled`), localized date range bounds, goal statement, progress capacity summary, and contextual action buttons (`Start Sprint`, `Complete & Retrospective`, `Edit Scope`, `View Retrospective`, `Edit Details`).
  - `SprintProgressCapacity.tsx` (`sprint-progress-capacity.css`, `SprintProgressCapacity.test.tsx`): Visual story points completion bar, target capacity meter, percentage calculation, over/under capacity badge indicators, and zero-denominator / error / loading skeleton handling.
  - `SprintTaskCommitmentList.tsx` (`sprint-task-commitment-list.css`, `SprintTaskCommitmentList.test.tsx`): Interactive task commitments list with status checkboxes, story points, project tags, committed vs scope-addition badges, add/remove scope triggers, and empty/error states.
  - `SprintScopeChangeHistory.tsx` (`sprint-scope-change-history.css`, `SprintScopeChangeHistory.test.tsx`): Timeline log of scope changes after sprint start (added tasks, removed tasks, point adjustments) with timestamps, impact deltas, and reason notes.
  - `SprintFormDialog.tsx` (`sprint-form-dialog.css`, `SprintFormDialog.test.tsx`): Accessible form dialog for creating/editing a sprint with fields for name, goal, start date, end date, target capacity story points, and validation for required fields and date sanity (`endDate >= startDate`).
  - `SprintRetrospectiveDialog.tsx` (`sprint-retrospective-dialog.css`, `SprintRetrospectiveDialog.test.tsx`): Form dialog for completing a sprint and conducting a retrospective: summary metrics (completed points vs total points), retrospective inputs ("What went well", "What could be improved", "Action items", summary notes), and uncompleted task carry-over action.
