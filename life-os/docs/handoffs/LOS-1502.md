## Completed behavior

- **Comprehensive Cross-User Authorization Matrix Test Suite (`CrossUserAuthorizationMatrixIntegrationTests.java`)**:
  - Implemented 21 exhaustive integration tests using two isolated user sessions (`User A` and `User B`) verifying that User B cannot read, infer, tamper with, or mutate any data belonging to User A across all LifeOS domain boundaries.
  - Verified the **Indistinguishability Guarantee**: querying another user's entity returns `404 RESOURCE_NOT_FOUND` (or empty collection on list endpoints), identical to querying non-existent entities, preventing enumeration and side-channel leakage.
  - Verified **Cross-User Reference Rejection**: attempting to associate User A's `projectId` or `labelIds` when creating or updating User B's task is rejected with `400 BAD_REQUEST` (`INVALID_PROJECT` / `INVALID_LABEL`).
  - Verified domain isolation across:
    1. Identity, Profile & Sessions (`/user/profile`, `/user/preferences`, `/auth/security/sessions/{id}`).
    2. Projects & Milestones (`/projects/**`, `/projects/{id}/milestones/**`).
    3. Tasks, Subtasks, MIT, Dependencies, Recurring Tasks (`/tasks/**`, `/tasks/mit`, `/tasks/recurring-series/**`).
    4. Time Blocks & Calendar (`/time-blocks/**`, `/calendar/events`).
    5. Focus Sessions (`/focus-sessions/**`, `/focus-sessions/active`, `/focus-sessions/{id}/**`).
    6. Goals, Check-ins & Goal Links (`/goals/**`, `/goals/{id}/check-ins/**`, `/goals/{id}/links/**`).
    7. Habits, Entries, Pauses & Statistics (`/habits/**`, `/habits/{id}/entries/**`, `/habits/{id}/pauses/**`, `/habits/{id}/stats`).
    8. Notes & Brain Dump (`/notes/**`, `/brain-dump-items/**`, `/brain-dump-items/{id}/convert/task`).
    9. Sprints, Weekly Plans & Reviews (`/sprints/**`, `/reviews/draft`, `/reviews/{id}`).
    10. Labels, Comments & Activity (`/labels/**`, `/tasks/{id}/comments/**`, `/tasks/{id}/activity`).
    11. Search, Reports & Exports (`/search`, `/reports/export/csv/{token}`, `/auth/export/status`, `/notifications/**`).

- **Cross-User Authorization Matrix Documentation (`46-CROSS-USER-AUTHORIZATION-MATRIX.md`)**:
  - Documented core security invariants, row-level scoping guarantees, indistinguishability principle, and a complete endpoint-by-endpoint authorization matrix covering all LifeOS REST routes and test mappings.
