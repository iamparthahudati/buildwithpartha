## Completed behavior

Added an authenticated OpenAPI 3.1 JSON document at `/life-os/api/v1/openapi` without enabling interactive Swagger UI. The document intentionally starts with no product paths and defines the relative same-origin API server, browser session and CSRF schemes, safe shared Problem Details schemas/responses, and the zero-based pagination envelope.

The backend test requests and validates the generated runtime document, then writes that exact checked response to `build/openapi/life-os-openapi.json`. The hosted backend check fails if the file is absent and uploads it as the `life-os-openapi` artifact with 14-day retention.
