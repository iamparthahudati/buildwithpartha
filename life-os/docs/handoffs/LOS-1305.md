## Completed behavior

- **Recurring Task Series & Exception Domain Aggregates (`tech.buildwithpartha.lifeos.task.domain`)**:
  - Modeled `RecurrenceFrequency` enum (`DAILY`, `WEEKLY`, `MONTHLY`, `WEEKDAY`, `INTERVAL`, `AFTER_COMPLETION`).
  - Modeled `RecurrenceEndMode` enum (`NEVER`, `UNTIL_DATE`, `COUNT`).
  - Modeled `RecurrenceExceptionType` enum (`SKIPPED`, `RESCHEDULED`, `DELETED`, `OVERRIDDEN`).
  - Modeled `RecurringTaskSeries` domain aggregate record enforcing invariants (non-blank title, non-negative estimate minutes, interval >= 1, valid IANA time zone identifier via `ZoneId`, mandatory `endDate` for `UNTIL_DATE` end mode, and positive `endCount` for `COUNT` end mode).
  - Modeled `RecurringTaskException` domain record representing per-occurrence exception rules (skip, reschedule date, delete, override task link, reason).
  - Modeled `RecurringTaskSeriesRepository` domain repository interface.
  - Extended `Task` domain record with `recurringSeriesId` and `recurrenceOccurrenceDate` while preserving backward compatibility for existing normal tasks (`recurringSeriesId IS NULL`).

- **JPA Persistence & Database Schema (`tech.buildwithpartha.lifeos.task.infrastructure` & Flyway)**:
  - Migration `V31__recurring_tasks_schema.sql`:
    - Created `recurring_task_series` table with check constraints, foreign keys, and indexes.
    - Created `recurring_task_exceptions` table with unique constraint on `(series_id, occurrence_date)`, type check constraint, foreign keys, and indexes.
    - Altered `tasks` table to add `recurring_series_id` (foreign key `ON DELETE SET NULL`) and `recurrence_occurrence_date`.
  - Updated `src/test/resources/schema.sql` to mirror `V31` schema additions in H2 test environment.
  - Created `RecurringTaskSeriesEntity` and `RecurringTaskExceptionEntity` JPA entities.
  - Created `RecurringTaskSeriesJpaRepository` and `RecurringTaskExceptionJpaRepository` Spring Data JPA interfaces.
  - Created `JpaRecurringTaskSeriesRepository` adapter implementing `RecurringTaskSeriesRepository`.
  - Updated `TaskEntity` and `JpaTaskRepository` to map `recurringSeriesId` and `recurrenceOccurrenceDate`.

- **Test Coverage & Verification**:
  - `RecurringTaskSeriesDomainTests`: Unit tests verifying domain creation, invariants, time zone validation, end mode checks, and exception records.
  - `JpaRecurringTaskSeriesRepositoryTests`: Spring Data JPA integration tests verifying series and exception persistence and queries.
  - `RecurringTaskSchemaIT`: Flyway integration test verifying table creation, tasks recurrence columns, and check constraints against real PostgreSQL/Testcontainers.
