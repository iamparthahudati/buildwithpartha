## Completed behavior

Built the global focus mini-player — providing persistent active focus session tracking, wall-clock monotonic ticking, a desktop hover/click popover, mobile-responsive inline rendering inside the drawer, and screen-reader status announcements — per `docs/backlog/EPIC-06-SHELL-TODAY.md` and `docs/backlog/EPIC-09-TIME-CALENDAR-FOCUS.md`.

- **`features/focus/api/focusApi.ts`** [NEW]:
  - Defines the `FocusSession` data models and status types.
  - Implements API call wrappers (`getActiveSession`, `startSession`, `pauseSession`, `resumeSession`, `completeSession`, `cancelSession`) for `/focus-sessions` utilizing the shared `apiRequest` client. Returns `null` on a 204 response (no active session) to comply with TanStack Query requirements.

- **`features/focus/hooks/useFocusSession.ts`** [NEW]:
  - Encapsulates TanStack React Query queries and mutations for session management.
  - **Monotonic Clock**: Evaluates actual remaining seconds against wall-clock time comparisons (`plannedEndTimestamp - Date.now()`) to prevent timer drift during browser tab throttling or CPU sleep states.
  - **localStorage fallback**: Synchronizes the session state to `localStorage` on any state update, and seamlessly falls back to local execution/updates if endpoints are absent or throw HTTP errors (such as 404 in dev).

- **`features/focus/components/FocusMiniPlayer.tsx`** (+ `focus-mini-player.css`, new focus component):
  - Renders a compact trigger button on desktop showing an `sm` (40px) `ProgressRing` with a tabular-num remaining time label.
  - Opens a popover on click containing the start session form with duration presets (`15m`, `25m`, `45m`) when idle, or the full `TimerRing` controls when active.
  - Collapses responsively below 768px to hide the trigger and render the start form or timer controls directly inline inside the mobile Drawer navigation.
  - **Accessible Announcements**: Employs `useAnnouncer` and `LiveRegion` to announce status transitions (paused, resumed, completed) only when the player's popover details are collapsed (avoiding double announcements when `TimerRing` is active/mounted).

- **`components/layout/AppShell.tsx`** [MODIFY] (+ `.test.tsx`):
  - Integrates `<FocusMiniPlayer />` inside `TopBar`'s `focusSlot` prop.
  - Updated `AppShell.test.tsx` to wrap tests in `QueryClientProvider` and `AuthSessionProvider`, mock focus fetches, and specifically target the main app-shell announcer to prevent collision with the mini-player's status announcements.

- **Catalog Integration** [MODIFY]:
  - Registered `FocusMiniPlayer` in `navigationEntries.tsx` and defined a Query-wrapped interactive demo in `NavigationDemos.tsx`.
  - Wrapped `AppShellDemo` inside `LayoutDemos.tsx` in `QueryClientProvider` and `AuthSessionProvider` to prevent crashes when rendering the layout catalog.
