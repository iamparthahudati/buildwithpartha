## Completed behavior

Implemented complete security settings and session management functionality across both frontend and backend (LOS-0516), conforming to `docs/06-SECURITY.md`, `docs/05-API-CONVENTIONS.md`, and `docs/backlog/EPIC-05-IDENTITY.md`:

- **Backend Security Endpoints & Services (`tech.buildwithpartha.lifeos.auth`)**:
  - `POST /auth/change-password`: Authenticated password change endpoint verifying the caller's current password against their stored Argon2id credential, enforcing password length and common exposure policy, updating the credential hash, revoking all other active sessions while preserving current session, and enqueuing a security alert email.
  - `GET /auth/sessions`: Authenticated active sessions listing endpoint providing device hints, created timestamp, last active timestamp, and `isCurrent` identification for the caller's active session.
  - `DELETE /auth/sessions/{sessionId}`: Single-session revocation endpoint allowing users to terminate individual sessions safely.
  - `POST /auth/sessions/revoke-others`: Bulk session revocation endpoint allowing users to sign out of all other devices simultaneously.
  - Application services: `ChangePasswordService` and `SessionManagementService`.
  - Repository methods in `SessionRepository`, `JpaSessionRepository`, and `SessionJpaRepository`.
  - Unit and integration tests: `ChangePasswordServiceTests`, `SessionManagementServiceTests`, and `SecurityControllerTests`.

- **Frontend Security Features & UI (`apps/web/src/features/auth` & `@features/settings`)**:
  - `features/auth/api/authApi.ts`: Added typed API client methods `changePassword`, `listSessions`, `revokeSession`, and `revokeAllOtherSessions`.
  - `features/auth/model/securityValidation.ts`: Client-side validation for change password (current password required, new password minimum 8 / maximum 128 characters, distinct from current password, confirmation match).
  - `features/auth/model/securityFieldErrors.ts`: Maps backend ProblemDetails error codes (`INVALID_CURRENT_PASSWORD`, `TOO_SHORT`, `COMMONLY_EXPOSED`, `REQUIRED`) to clear user-facing messages.
  - `features/auth/hooks/`: TanStack Query hooks `useChangePassword`, `useUserSessions`, `useRevokeSession`, and `useRevokeAllOtherSessions` with cache invalidation on mutations.
  - `features/settings/components/SecuritySettingsPanel.tsx`: Full security settings UI featuring Change Password card with live validation and success alert, and Active Sessions card with device badges, formatted timestamps, individual session revocation with `ConfirmDialog`, and bulk "Sign out all other devices" with `ConfirmDialog`.
  - Wired `SecuritySettingsPanel` into `SettingsScreen.tsx` (Security tab).
  - Unit tests in `securityValidation.test.ts`, `securityHooks.test.tsx`, `SecuritySettingsPanel.test.tsx`, and `SettingsScreen.test.tsx`.
