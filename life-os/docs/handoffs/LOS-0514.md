## Completed behavior

Implemented the full 4-step frontend onboarding flow UI and step screens connecting to the onboarding persistence endpoints (LOS-0513), per `docs/25-ONBOARDING-SPECIFICATION.md`, `docs/wireframes/01-AUTH-ONBOARDING.md`, and `docs/backlog/EPIC-05-IDENTITY.md`:

- **Model Layer (`apps/web/src/features/onboarding/model`)**:
  - `timezones.ts`: IANA timezone detection via `Intl.DateTimeFormat().resolvedOptions().timeZone`, timezone validity testing, sorted timezone list with UTC priority, deterministic timezone live preview ("Your Today" and local time calculation).
  - `onboardingValidation.ts`: Step-specific client validation for Welcome form (display name bounds/non-empty), Time and Week form (valid IANA timezone / UTC, week start day), and Planning Defaults form (valid 1..7 working days, start/end time format, overnight schedule validation, focus/break duration bounds).
  - `onboardingFieldErrors.ts`: Maps backend ProblemDetails `errors: [{ field, code }]` into step-specific field validation messages.
  - `onboardingSteps.ts`: Step list, step titles, and step number types (1: Welcome, 2: Time & week, 3: Planning defaults, 4: Start).
  - Unit tests in `timezones.test.ts` and `onboardingValidation.test.ts`.

- **Hooks Layer (`apps/web/src/features/onboarding/hooks`)**:
  - `useOnboarding.ts`: TanStack Query hook fetching `/onboarding` status and profile/preference state.
  - `useUpdateWelcomeStep.ts`: Mutation hook for Step 1 (`PUT /onboarding/welcome`), synchronizing updated display name to the active `AuthSessionProvider`.
  - `useUpdateTimeAndWeekStep.ts`: Mutation hook for Step 2 (`PUT /onboarding/time-and-week`), synchronizing updated timezone to `AuthSessionProvider`.
  - `useUpdatePlanningDefaultsStep.ts`: Mutation hook for Step 3 (`PUT /onboarding/planning-defaults`), supporting both save and skip.
  - `useCompleteOnboarding.ts`: Mutation hook for Step 4 (`POST /onboarding/complete`), finalizing onboarding.
  - Unit tests in `onboardingHooks.test.tsx`.

- **Component Layer (`apps/web/src/features/onboarding/components`)**:
  - `OnboardingProgressRail.tsx`: Responsive progress rail with 4 named steps, checked badge states for completed/past steps, and mobile-responsive compact progress bar.
  - `WelcomeStep.tsx`: Step 1 form displaying confirmed email (read-only), editable display name, inline error summary / field validation, and submit action.
  - `TimeAndWeekStep.tsx`: Step 2 form with searchable Combobox for IANA timezones, one-click shortcuts for browser-detected timezone and UTC, live date/time preview card, week start day picker, and locale picker.
  - `PlanningDefaultsStep.tsx`: Step 3 form with working days checkboxes (Mon-Sun), start/end time inputs, overnight schedule toggle, daily focus target, focus duration, break duration, and a "Skip for now" action.
  - `StartStep.tsx`: Step 4 clean workspace initialization showing "Start empty" recommendation and finish setup trigger.
  - `OnboardingScreen.tsx`: Top-level coordinator managing loading/error states, server resume determination (`lastCompletedStep`), step transitions, sign-out in header, global error alert banners, and redirect to `/life-os/app/today` upon completion.
  - `onboarding-screen.css`: Token-only CSS styling compliant with design token and color contrast rules.
  - Component tests in `OnboardingScreen.test.tsx` and `OnboardingSteps.test.tsx`.

- **Feature Entrypoint (`apps/web/src/features/onboarding/index.ts`)**:
  - Clean public export surface for screens, components, hooks, model utilities, and types.
