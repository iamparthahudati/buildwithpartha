## Completed behavior

- Replaced the provisional LOS-0605 API model with the complete LOS-0913 Focus Session response and endpoint contract, including server timestamps, accumulated focus/break seconds, planned durations, canonical session IDs, optimistic versions, interruption records, and all lifecycle routes.
- Added an idempotency key to every start, transition, terminal, and interruption write. Transitions target the canonical session ID and version; stale, invalid, and already-active `409` responses trigger authoritative recovery instead of applying a client-side guess.
- Restores the active Focus Session at application bootstrap, on focus-window refresh, every 30 seconds while active, after a content-free cross-tab change signal, and immediately after reconnection.
- Calculates display time from the server-authoritative accumulated duration at response time plus elapsed time since the browser receipt anchor. It recomputes from timestamps rather than counting interval callbacks, so background throttling and device sleep do not create timer drift.
- Automatically moves an expired focus phase into its planned break, or completes immediately when no break was planned. An expired break completes the session. A process-wide transition key prevents duplicate effects from the mini-player and full route in one tab; backend idempotency, optimistic versions, account locking, and semantic replay reconcile simultaneous tabs without duplicate Task time or Time Block completion.
- Removed all Focus Session `localStorage` reads/writes and offline-created session fallbacks. The last confirmed in-memory snapshot remains visible and estimated while offline, controls are disabled with explicit copy, an offline refresh asks the user to reconnect, and no mutation is described as saved without server acknowledgement.
- Added the protected `/life-os/app/focus` route over the controlled LOS-0914 surface. It supports start/pause/resume/complete/cancel/skip-break, distraction capture, explicit notification permission, next-session duration settings, terminal summaries, recovery states, and linked Task/Time Block titles and canonical links.
- Updated the global mini-player to share the canonical query and clock, use the Account's focus/break defaults, show the active phase, expose the full Focus Mode link, and leave destructive completion/cancellation to the full surface's exact confirmations.
- Connected Task Details' existing Focus Mode links and added canonical Time Block and Today Task/schedule deep links. Successful transitions invalidate Today on every state change, linked Time Block and Calendar data on start/complete/cancel, and linked Task data only when completion records confirmed time.
- Added “Focus Mode” route title resolution so the Top Bar, document title, route focus target, and navigation announcement use the canonical experience name.
