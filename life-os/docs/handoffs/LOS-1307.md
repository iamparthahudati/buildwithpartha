## Completed behavior

- **Recurrence Contract & Logic Engine (`apps/web/src/components/forms/recurrenceContract.ts`)**:
  - Defined recurrence types: `RecurrenceFrequency` (`DAILY`, `WEEKLY`, `MONTHLY`, `WEEKDAY`, `INTERVAL`, `AFTER_COMPLETION`), `RecurrenceEndMode` (`NEVER`, `UNTIL_DATE`, `COUNT`), `RecurrenceDayOfWeek` (`MONDAY`..`SUNDAY`), and `RecurrenceEditScope` (`THIS_OCCURRENCE`, `THIS_AND_FUTURE`, `SERIES`).
  - `validateRecurrenceRule`: Validates integer interval values (>=1), required days of week for weekly patterns, valid day of month (1-31) for monthly patterns, end date ordering for `UNTIL_DATE`, and positive count for `COUNT`.
  - `formatRecurrenceRuleSummary`: Generates human-readable rule summaries (e.g. "Repeats weekly on Mon, Wed, Fri, until 2026-12-31").
  - `calculateNextOccurrences`: Calculates next occurrence dates preview with month-end day clamping and weekend skipping.

- **Recurrence Editor Component (`apps/web/src/components/forms/RecurrenceEditor.tsx` & `recurrence-editor.css`)**:
  - Implemented controlled form editor component.
  - Configurable frequency selection, cadence interval input, day-of-week toggle buttons for weekly frequency, day-of-month selector for monthly frequency, end mode options (`NEVER`, `UNTIL_DATE`, `COUNT`), end date picker, and occurrence count input.
  - Live human-readable summary card and next-occurrence date preview list.
  - Offline restriction indicator banner for offline queued mutations.
  - Fully accessible fieldset, legends, ARIA roles, and keyboard navigation.

- **Recurrence Edit Scope Dialog (`apps/web/src/components/feedback/RecurrenceEditScopeDialog.tsx` & `recurrence-edit-scope-dialog.css`)**:
  - Implemented modal dialog for selecting scope when editing or deleting recurring tasks (`THIS_OCCURRENCE`, `THIS_AND_FUTURE`, `SERIES`).
  - Support for edit and delete action variants with contextual title, description, and primary/danger action buttons.
  - Keyboard focus management, Escape key handling, and backdrop click routing.

- **Design System Catalog Integration (`apps/web/src/catalog`)**:
