## Completed behavior

Replaced the documentation-only workflow with a four-check cross-stack GitHub Actions foundation for every pull request/push targeting `develop` or `master`. Documentation/dependency/CI policy, the complete frontend gate plus production build, the clean backend gate, and full-history Gitleaks scanning are independently required.

Actions are pinned to full commit SHAs. npm caches are tied to the LifeOS lockfile, pull-request Gradle caches are read-only, permissions are read-only, duplicate branch/ref runs cancel safely, and each job has a bounded timeout. Dependabot now proposes GitHub Actions updates for explicit review.

GitHub branch protection is active on `develop` and `master`: up-to-date pull requests, all four checks and resolved conversations are required; administrators are included; force pushes and deletion are disabled. `develop` is the remote default branch. The settings are reproducible through the committed protection script.
