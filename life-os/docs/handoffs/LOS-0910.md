## Completed behavior

- Added a frontend Calendar event model that mirrors the LOS-0909 aggregation contract, including canonical `sourceId`, `sourceType`, timed/all-day distinction, status, and optional Project/Task context.
- Added local-date-safe week/month range, period navigation, grouping, ordering, source metadata, and timezone-aware event-time formatting helpers.
- Built `CalendarHeader` with previous/next Day, Week, or Month navigation, a local Today target, a controlled three-view switcher, and optional Add Time Block action.
- Built controlled `CalendarFilterLegend` checkboxes for Time Blocks, due Tasks, milestones, Habits, and Reviews, with redundant text and color identification plus optional counts.
- Built `EventChip` with source, time, title, completed state, compact/comfortable densities, and canonical-event selection callbacks.
- Built a distinct `AllDayLane`, accessible `OverflowList` for dense days, and a semantic grouped `CalendarListAlternative` with honest empty state.
- Built loading/ready/empty-capable Day, Week, and six-week Month grids. Week and Month date controls support arrow/Home/End navigation and touch activation; Month supports two-dimensional movement. Week switches to a semantic list at small widths, and Month keeps a selected-date agenda below its navigable grid.
- Added catalog specimens covering header, every source chip, overflow, source filters, all three grids, and the list alternative.
