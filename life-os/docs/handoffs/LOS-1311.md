# LOS-1311 handoff

- Status: Completed
- Branch/commit: `feature/LOS-1311-integrate-attachments`
- Date: 2026-09-02

## Completed behavior

- **Created Attachment Domain Module (`src/features/attachments`)**:
  - Implemented `model/attachment.ts` defining frontend types (`ClientAttachment`, `AttachmentStatus`, `AttachmentEntityType`, `AttachmentResponse`, `AttachmentListResponse`) and status mapping (`PENDING_SCAN` -> `scanning`, `CLEAN` -> `ready`, `QUARANTINED` -> `blocked`).
  - Implemented `api/attachmentsApi.ts` for listing, retrieving, uploading (FormData with CSRF token), downloading (`apiBlobRequest`), and deleting entity attachments.
  - Implemented `hooks/useAttachments.ts` (React Query query hook) and `hooks/useAttachmentMutations.ts` (React Query mutation hook with optimistic in-flight upload state tracking).
  - Exposed module through public entrypoint `index.ts`.
- **API Client Extensions (`@lib/apiClient`)**:
  - Updated `apiRequest` to support `FormData` body payloads without forcing `Content-Type: application/json`.
  - Added `apiBlobRequest` for streaming binary attachment payload downloads while maintaining same-origin session credentials, CSRF protection, and Problem Details error handling.
- **Integrated Attachments with Task Details (`IntegratedTaskDetails.tsx`)**:
  - Connected `useAttachments("TASK", taskId)` and `useAttachmentMutations("TASK", taskId)` to pass live attachments, upload/download/cancel/retry/delete handlers to `TaskDetailsScreen`.
  - Respects feature toggle `lifeos.features.attachments.enabled` (hiding tab when toggle is false or backend returns 404).
- **Integrated Attachments with Project Details (`ProjectDetailsRoute.tsx`, `ProjectDetailsScreen.tsx`)**:
  - Connected `useAttachments("PROJECT", projectId)` and `useAttachmentMutations("PROJECT", projectId)` to pass live attachment state and handlers to `ProjectDetailsScreen`.
  - Dynamically renders the "Files & Attachments" tab when feature toggle is enabled.
- **Package Invariants & Quality Gate**:
  - Passed quality gate (`npm run verify:quality` in `apps/web`) with zero ESLint/TypeScript/boundary errors and zero token violations.
  - Passed full unit test suite (330 test files, 2451 tests passing).
