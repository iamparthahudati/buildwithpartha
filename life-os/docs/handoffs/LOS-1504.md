- **Responsive/Browser Matrix Automated Test Suite (`e2e/browser-matrix/browser-matrix.spec.ts`)**:
  - **Section 1 — Public Route Rendering**: Verifies Login, Signup, and Forgot Password render without horizontal overflow and with CSS custom property (design token) resolution across all browser engines.
  - **Section 2 — Authenticated Shell Rendering**: Verifies Today, Tasks, Projects, Notes, and Settings authenticated routes render `#lifeos-main-content` without horizontal overflow.
  - **Section 3 — Touch Target Sizing**: Verifies all visible `button`, `[role="button"]`, `a[href]`, and `[role="link"]` elements meet the 44×44 CSS pixel minimum on narrow viewports (width ≤ 600 px). Skipped on wide desktop targets.
  - **Section 4 — Core Interaction (Quick Add)**: Opens the Quick Add dialog or falls back to the keyboard shortcut, fills the task title, and dismisses; asserts zero console errors during the interaction.
  - **Section 5 — Service Worker Registration**: Loads the authenticated shell and asserts no Service-Worker-related console errors fire.
  - **Section 6 — Viewport Breakpoints**: Tests Today dashboard and Login page at 320, 375, 768, 1024, 1280, and 1440 px widths for zero horizontal overflow (covering WCAG 1.4.10 reflow at 320 px).
  - **Section 7 — HTML `lang` and Page Titles**: Asserts all four representative routes (`/login`, `/signup`, `/app/today`, `/app/tasks`) set a non-empty `<title>` and `html[lang]` attribute.

- **Browser Support Policy (`docs/48-BROWSER-SUPPORT-POLICY.md`)**:
  - Defined Tier-1 (Chrome, Firefox, Safari, Edge — blocking), Tier-2 (Samsung Internet, iOS browsers, Brave — best-effort), and Tier-3 (IE, legacy Edge, Opera Mini — unsupported) classification.
  - Documented supported viewport breakpoints (320/375/414/768/1024/1280/1440 px) and their representative devices.
  - Recorded CSS feature policy (Custom Properties, Grid, Flexbox, `focus-visible`, `prefers-reduced-motion`, `forced-colors`, `mask`) and JS baseline (ES2022, ESM, `ResizeObserver`, `IntersectionObserver`, `IndexedDB`, `serviceWorker`, `Crypto.subtle`).
  - Documented 5 known cross-browser inconsistencies with accepted mitigations: Safari `backdrop-filter` GPU jank (accepted), Firefox `mask` shorthand (resolved), Firefox `scrollbar-width` visual difference (accepted), iOS virtual keyboard `position: fixed` (monitored), Edge same-engine as Chrome (implicit pass).
  - Defined update policy tied to major browser releases.
