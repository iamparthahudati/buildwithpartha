## Completed behavior

- Built reusable Spring MVC HTTP caching policy, ETag generation, and Cloudflare proxy-bypass infrastructure:
  - `ApiCachePolicyFilter` servlet filter (`tech.buildwithpartha.lifeos.common.cache`) enforcing explicit default security and cache-bypassing headers for all private API responses (`/life-os/api/*`, `/api/*`):
    - `Cache-Control: no-store, private, no-cache, max-age=0, must-revalidate`
    - `Pragma: no-cache`
    - `Expires: 0`
    - `Vary: Accept-Encoding, Cookie, Authorization`
    - `CDN-Cache-Control: no-store`
    - `Cloudflare-CDN-Cache-Control: no-store`
  - `@CachePolicy` annotation for controller classes and handler methods to declaratively specify custom cache-control directives (e.g., `@CachePolicy("private, max-age=60")`).
  - `CachePolicyInterceptor` handler interceptor mapping custom `@CachePolicy` annotations to response headers.
  - `CacheConfiguration` registering `ShallowEtagHeaderFilter` for path patterns `/life-os/api/*` and `/api/*`, enabling automatic content hash ETags on GET responses and HTTP 304 `Not Modified` response handling when `If-None-Match` header matches.
  - `ETagUtils` helper class for formatting and matching strong and weak ETags.
- Added unit and integration test coverage (`ETagUtilsTests`, `ApiCachePolicyFilterTests`, `CachePolicyIntegrationTests`):
  - Verified default security and proxy-bypass headers across API endpoints.
  - Verified custom `@CachePolicy` annotation overrides.
  - Verified ETag header generation on GET requests and HTTP 304 `Not Modified` processing with matching `If-None-Match`.
  - Verified cache invalidation on resource mutations (POST/PUT updates producing fresh 200 OK responses with updated ETags).
  - Verified account isolation ensuring no cross-account cache sharing occurs (`private`, `Vary: Cookie, Authorization`).
