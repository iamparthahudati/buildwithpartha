## Completed behavior

### Comprehensive STRIDE Threat Model Review (`50-THREAT-MODEL.md`)

Conducted an exhaustive data-flow and STRIDE-style threat model review across all nine LifeOS operational and architectural boundaries:

1. **Auth, Identity & Sessions**:
   - Evaluated spoofing (forged/expired cookies, session hijacking, fixation), tampering (missing CSRF tokens), repudiation (audit logs), information disclosure (anti-enumeration, timing attacks), and privilege escalation.
   - Verified Argon2id password hashing, constant-time verification, `HttpOnly`/`Secure`/`SameSite=Lax` cookies, and session invalidation/revocation on logout and password change.

2. **API & REST Surface**:
   - Evaluated Insecure Direct Object References (IDOR), cross-tenant parameter tampering, actuator information disclosure, stack trace leakage, and header injection.
   - Enforced row-level user scoping on all queries (`userId = :userId`), the **Indistinguishability Guarantee** (foreign/non-existent IDs return uniform `404 RESOURCE_NOT_FOUND`), foreign reference validation (400 validation error on cross-user associations), RFC 7807 `ProblemDetail` responses, alphanumeric correlation ID sanitization, and strict actuator lockdown (only public aggregate `/actuator/health/liveness` and `/readiness` exposed).

3. **Database & Persistence Layer**:
   - Evaluated SQL injection, unauthorized database access, privilege escalation, concurrent lost updates, and backup exposure.
   - Enforced 100% parameterized JPA/Hibernate queries, dedicated least-privilege `lifeos_app` user, private Docker bridge isolation, optimistic concurrency locking (`@Version`), and GPG/AES-256 encrypted backups with `600` file permissions.

4. **File Attachments & Upload Pipeline**:
   - Evaluated stored XSS / remote code execution, path traversal overwrite, storage exhaustion DoS, and cross-user download IDOR.
   - Enforced strict MIME whitelist (`AttachmentMimeValidator`), magic bytes validation, rejection of dangerous extensions (`.exe`, `.sh`, `.bat`, `.html`, `.svg`), UUID disk keys (`storageKey`), per-file (10MB) and per-user (100MB) quotas, and authenticated ownership checks on downloads with `X-Content-Type-Options: nosniff`.

5. **Mail & Transactional Notifications**:
   - Evaluated SMTP / CRLF injection, token interception in transit, and notification PII leakage.
   - Enforced strict RFC 5322 regex email normalization, newline stripping, TLS 1.3 transit, short token TTLs (15 min for reset, 24h for verification), single-use token invalidation, and zero sensitive notes / password data in email copy.

6. **Cloudflare, Edge Proxy & Network Security**:
   - Evaluated Man-in-the-Middle (MitM) attacks, DDoS, origin IP bypass, and clickjacking/framing.
   - Enforced Full (Strict) TLS 1.3, Cloudflare WAF/DDoS rules, VPS UFW firewall restricted exclusively to Cloudflare IP ranges, HSTS with 1-year max-age and preload, and `X-Frame-Options: DENY`.

7. **Offline Cache, IndexedDB & Service Worker**:
   - Evaluated credential exposure in browser storage, mutation replay conflicts, and shared-device residual data.
   - Enforced zero persistent auth credentials in IndexedDB/LocalStorage, client-generated idempotency keys (`Idempotency-Key: UUID`) with optimistic concurrency tokens (`version`), and complete purge of client-side stores upon explicit logout.

8. **Exports, Reports & Data Portability**:
   - Evaluated CSV / spreadsheet formula injection, cross-user export IDOR, and export DoS resource exhaustion.
   - Enforced CSV formula trigger sanitization (prepending `'` to `=`, `+`, `-`, `@`), authenticated user-scoped archive generation, short-lived (1-hour) temporary storage with automated purge, and asynchronous export processing.

9. **Admin, VPS, Containers & Operations**:
   - Evaluated god-mode backdoor accounts, container root breakout, git secret leakage, and log PII exposure.
   - Verified zero "super-admin" bypasses in application code (strictly single-tenant), unprivileged non-root container execution (`UID 10001`), CI/CD secret scanning with host `.env.production` files (`600` permissions), and Logback PII/credential redaction formatters.

### High-Risk Mitigation & Verification Ledger

Every identified High or Critical risk has an assigned Owner, Architectural Mitigation Strategy, and Automated Test Mapping across the 10 core high risks (HR-01 through HR-10).

### Backend — New STRIDE Threat Model Test Suite (`ThreatModelSecurityIntegrationTests.java`)

Implemented 13 end-to-end integration tests in `ThreatModelSecurityIntegrationTests.java` verifying STRIDE threat model invariants:
- **STRIDE [S] Spoofing**:
  - `TM-S-1`: Forged / non-existent session cookie rejected with 401 UNAUTHORIZED.
  - `TM-S-2`: Expired session token rejected with 401 UNAUTHORIZED.
  - `TM-S-3`: Revoked session cannot be reused to access protected endpoints.
- **STRIDE [T] Tampering**:
  - `TM-T-1`: Mutation request without CSRF header rejected with 403 FORBIDDEN.
  - `TM-T-2`: Cross-user foreign reference tampering rejected with 400 BAD_REQUEST.
- **STRIDE [R] Repudiation**:
  - `TM-R-1`: Request correlation ID safely echoed / generated in responses.
  - `TM-R-2`: Session listing provides auditable client metadata.
- **STRIDE [I] Information Disclosure**:
  - `TM-I-1`: Actuator internals (`/env`, `/heapdump`, `/beans`, `/mappings`) completely denied.
  - `TM-I-2`: Public health readiness and liveness probes accessible without internal leakage.
  - `TM-I-3`: Non-existent vs foreign ID access returns indistinguishable 404 RESOURCE_NOT_FOUND.
  - `TM-I-4`: Invalid login credentials produce generic anti-enumeration response.
- **STRIDE [D] Denial of Service**:
  - `TM-D-1`: Attachment validator rejects executable, script, and dangerous extensions (`.exe`, `.sh`, `.bat`, `.html`, `.svg`).
- **STRIDE [E] Elevation of Privilege**:
  - `TM-E-1`: User B cannot delete or mutate User A's project or task.
