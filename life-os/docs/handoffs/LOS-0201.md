## Completed behavior

Created the first standalone, executable LifeOS frontend in `apps/web` without modifying or coupling it to the existing main website. Local development serves the application at `http://localhost:5173/life-os/`; production builds rewrite JavaScript and CSS asset references beneath `/life-os/assets/`.

The temporary public readiness view confirms the frontend foundation only. It is not a shortcut around the component-first roadmap and contains no fake user data, authentication claim or finished product screen.

## Files and contracts changed

- Locked React 19.2.8, React DOM 19.2.8, TypeScript 7.0.2, Vite 8.2.1 and the React Vite plugin in an isolated npm package/lockfile.
- Added strict TypeScript configuration with modern JSX, bundler module resolution and additional unsafe-index/optional-property checks.
- Added Vite SPA configuration with base `/life-os/`, fixed local/preview ports and the 2026 Baseline Widely Available production target.
- Added the HTML/bootstrap entry, temporary readiness view, responsive/reduced-motion-safe starter styling and app-local ignore rules.
- Added a build-output test that fails when generated JavaScript/CSS assets escape the nested LifeOS path.
- Updated the documentation validator to exclude generated dependency/build directories introduced by application bootstraps.
- Replaced the reserved web README with reproducible install, local preview and validation instructions.
