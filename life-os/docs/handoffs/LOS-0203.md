## Completed behavior

LifeOS now resolves its frontend and backend dependency graphs reproducibly. The web application uses exact direct versions, an exact npm package-manager version and the committed npm lockfile. The API uses strict Gradle locking for all resolvable direct and transitive configurations while retaining the exact checksummed Gradle wrapper.

Weekly Dependabot proposals are isolated to the LifeOS npm and Gradle directories and target `develop`. Minor/patch proposals are grouped per ecosystem; major changes remain individually visible. Bot branches are triage inputs and cannot bypass the required LOS ticket/feature-branch/review flow.
