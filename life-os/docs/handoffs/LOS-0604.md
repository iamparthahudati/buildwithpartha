## Completed behavior

Built the Quick Add overlay dialog (`QuickAddDialog`) enabling users to quickly capture or schedule items from anywhere in the application.

- **Global keyboard shortcut hook** (`components/feedback/useQuickAddShortcut.ts`): Binds `q` or `Option+Q` (`Alt+Q`) to toggle the dialog. Includes robust logic to prevent triggering when the user is focused on interactive inputs, textareas, select dropdowns, or contenteditable areas.
- **Unified Switcher Dialog UI** (`components/feedback/QuickAddDialog.tsx` + `quick-add-dialog.css`):
  - Composes `FormDialog` to present a fast button grid for primary types (Task, Brain Dump, Time Block, Note) and a "More" dropdown for online-only types (Project, Habit Entry, Goal Check-in).
  - Preserves local, in-progress form inputs independently for each type when switching back and forth, preventing accidental data loss.
  - Implements field validation with `FormFieldGroup` and `FormErrorSummary`, shifting focus directly to the summary on failure.
  - Integrates network connectivity listeners (`navigator.onLine`) to enforce offline safety: disables online-only types with warning banners, and queues safe drafts (Task, Note, Brain Dump) locally with toast confirmations.
  - Supports database constraint recovery testing via a special title value `"force-fail"` which simulates a server error while preserving entered inputs.
  - Automatically redirects and closes when "More options" is clicked, routing to the canonical list screens.
- **Application shell integration**: Integrated the state hook and modal dialog in `ProtectedShell` in `AppRouter.tsx`, and exported them from `components/feedback/index.ts`.
- **Validation Form Bypass**: Added `noValidate` to `<form>` in `FormDialog.tsx` to ensure React validation states (`FormErrorSummary`) display properly and are not bypassed or blocked by native browser validation.
- **Import consolidation**: Cleaned up form imports in `QuickAddDialog.tsx` to resolve all primitives from `@components/forms`.
