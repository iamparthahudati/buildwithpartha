## Completed behavior

- Implemented ordered subtask REST endpoints under `/tasks/{taskId}/subtasks`:
  - `POST /tasks/{taskId}/subtasks` — Add subtask item with title and position.
  - `PUT /tasks/{taskId}/subtasks/{subtaskId}` — Update subtask title, completed status, or position.
  - `PATCH /tasks/{taskId}/subtasks/{subtaskId}/toggle` — Toggle subtask completion status.
  - `DELETE /tasks/{taskId}/subtasks/{subtaskId}` — Delete subtask item.
  - `PUT /tasks/{taskId}/subtasks/reorder` — Reorder subtasks by ordered array of IDs.
- Implemented transactional task progress recalculation policy: when subtasks are added, toggled, updated, or deleted, task progress percentage is automatically recalculated (`progress = (completed / total) * 100`) and saved.
- Preserved user ownership checks (`userId` isolated; cross-user task or subtask lookups return `404 Not Found`).
