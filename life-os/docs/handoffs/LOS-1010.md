## Completed behavior

- Implemented authenticated REST API endpoints under `/reviews` for managing daily morning/evening, weekly, and monthly review rituals.
- Added `ReviewService` in `tech.buildwithpartha.lifeos.sprint.application` handling prompt generation, snapshot metric calculations, draft saving, finalization, skipping, and reopen policy enforcement.
- Created DTOs (`ReviewResponse`, `ReviewPromptsAndMetricsResponse`, `ReviewPromptResponse`, `ReviewAnswerResponse`, `ReviewItemDecisionResponse`, `ReviewSnapshotMetricsResponse`, `SaveReviewDraftRequest`, `FinalizeReviewRequest`, `SkipReviewRequest`) and application commands (`SaveReviewDraftCommand`, `FinalizeReviewCommand`, `SkipReviewCommand`).
- Added domain-specific exception `ReviewStateConflictException` mapped to HTTP `409 CONFLICT` with standard problem details when attempting to edit finalized/skipped reviews or when attempting to reopen finalized reviews.
- Added prompt definitions for `DAILY_MORNING`, `DAILY_EVENING`, `WEEKLY`, and `MONTHLY` review rituals matching `docs/27-REVIEW-RITUALS.md`.
- Updated `ReviewRepository`, `JpaReviewRepository`, and `ReviewJpaRepository` to support `findByUserId` listing ordered by start date desc.
- Updated `OpenApiArtifactTests` to validate OpenAPI spec generation for all `/reviews` paths and schemas in `build/openapi/life-os-openapi.json`.
- Added unit tests (`ReviewServiceTest.java`) and full MockMvc Spring Boot integration tests (`ReviewControllerTests.java`).
