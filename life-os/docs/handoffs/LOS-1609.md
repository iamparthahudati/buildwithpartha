## Completed behavior

- **Authored Application Data and File Backup Specification (`life-os/docs/43-APPLICATION-DATA-AND-FILE-BACKUP.md`)**:
  - Established canonical specification for automated application data and file backups, persistent versus transient data categorization taxonomy, recovery point objectives (RPO 24h nightly automated at 02:30 UTC), recovery time objectives (RTO < 15 minutes full restore), AES-256 GPG symmetric encryption standards (`gpg --symmetric --cipher-algo AES256`), SHA-256 checksum verification, structured JSON metadata manifests (`<backup>.json`), database-file backup consistency & restore ordering protocols (DB first at 02:00 UTC, app files second at 02:30 UTC; restores execute DB first, files second), post-restoration orphan reconciliation rules, retention schedules (30-day default nightly retention, 35-day backup expiry ceiling matching privacy lifecycle rules in `31-PRIVACY-DATA-LIFECYCLE.md` and `ADR-012`), status tracking (`/var/log/life-os/app-files-backup-status.json`), failure alert notification schema, full/partial disaster recovery runbooks, and secret-safe non-logging rules.

- **Created Automated Application File Backup Execution Script (`life-os/scripts/backup-app-files.sh`)**:
  - Executable shell script supporting `--target=production|staging|local`, `--output-dir=<dir>`, `--keep-days=<N>`, `--passphrase=<secret>`, `--dry-run`, `--skip-offsite`.
  - Handles target environment storage path resolution (`APP_ATTACHMENT_STORAGE_PATH`, `APP_EXPORT_STORAGE_PATH`), compressed tar archive creation (`.tar.gz`), AES-256 GPG encryption (`.tar.gz.gpg`), SHA-256 checksum file generation (`.sha256`), metadata JSON manifest creation (`.json`), off-VPS replication hook, retention cleanup sweep (`--keep-days`, default 35), status JSON recording (`app-files-backup-status.json`), and failure alert emission (`alerts.log`).

- **Created Automated Application File Restoration Execution Script (`life-os/scripts/restore-app-files-backup.sh`)**:
  - Executable shell script supporting `--backup-file=<path>`, `--target=production|staging|local`, `--passphrase=<secret>`, `--dry-run`, `--force`.
  - Performs pre-flight file existence and SHA-256 checksum validation, AES-256 GPG archive decryption into isolated temporary scratch buffer, archive extraction into target attachment/export storage directories, restoration audit logging (`app-files-restorations.json`), and outputs reminder for post-restoration DB-first ordering and orphan reconciliation.

- **Created Automated Verification Audit Script (`life-os/scripts/validate-app-files-backups.sh`)**:
  - Executable audit script testing specification compliance, script executable flags (`chmod +x`), backup dry-run execution, restore dry-run execution, AES-256 encryption standard assertions, 30/35-day retention pruning logic, non-logging secret redaction rules, and status file schema.
