## Completed behavior

- Added proxy-aware `ClientIpResolver` supporting configurable trusted proxies (`lifeos.security.trusted-proxies`) and parsing `X-Forwarded-For` proxy headers.
- Implemented `RateLimiterService` supporting thread-safe fixed/sliding window counters, periodic memory cleanup (`@Scheduled`), and Micrometer metrics counters (`lifeos.rate_limit.evaluations`).
- Implemented `RateLimitingInterceptor` and `RateLimitingWebConfig` enforcing rate limit policies across Search (30 req/min), Export (10 req/min), and non-auth Write-burst (60 req/min) operations.
- Refactored Auth rate-limiting adapters (`InMemorySignupRateLimiter`, `InMemoryLoginRateLimiter`, `InMemoryPasswordResetRateLimiter`, `InMemoryResendVerificationRateLimiter`) to delegate to `RateLimiterService`.
- Updated `RateLimitedException` and `ApiExceptionHandler` to return HTTP 429 `TOO_MANY_REQUESTS` with standard `Retry-After` header and safe Problem Details payload.
