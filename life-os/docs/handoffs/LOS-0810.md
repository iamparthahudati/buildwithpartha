## Completed behavior

- Added one typed TaskForm for create and edit flows, composed on the shared FormDialog and existing form atoms rather than introducing a parallel form system.
- Covers Task title, optional Project and description, canonical Task status and Product priority, due date/time, Estimate in canonical minutes, percentage progress, user-owned Labels, and the dated Most Important Task (MIT) designation.
- Converts due date/time entered in the Account's confirmed IANA timezone to a UTC API instant. It rejects partial values and nonexistent daylight-saving times; repeated times use the shared earlier-occurrence convention and warning.
- Preserves an existing MIT's local date while editing. New MIT selection uses today's Account-local date, explains that one Task per date is allowed, and is unavailable for Done or Cancelled Tasks.
- Provides `presentation="quick-add"`: Task title, optional Project, and due date/time appear first, with every canonical field available through “Show all task options.” Draft values stay in the same form state when expanded.
- Validates without clearing input, focuses the linked error summary after a failed submit, and lets summary actions focus composite Due date and Estimate fieldsets as well as atomic fields.
- Tracks all editable values for the shared discard guard. Pending saves prevent duplicate submission and field edits. Version conflicts keep values readable, block all submission paths, and offer a caller-controlled “Reload latest task” action.
- Added full and Quick Add catalog specimens plus public Task feature exports.
