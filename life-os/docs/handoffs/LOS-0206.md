## Completed behavior

Replaced placeholder backend domain directories with documented Java packages under `tech.buildwithpartha.lifeos`. The approved domain list, `common`, and `config` are now explicit source contracts rather than empty folders.

Added executable package rules that keep product domains independent, keep `common` domain-neutral, restrict domain subpackages to `api`, `application`, `domain`, and `infrastructure`, and enforce inward dependencies between those layers. Domain-layer code cannot depend on Spring or JPA. Test-only invalid fixtures prove that cross-domain, common-to-domain, outward-layer, and unapproved-package violations each fail the architecture suite.

Added a stable upper-snake-case `ErrorCode`, the server-diagnostic-only `CodedException` base type, and an immutable zero-based `PageResponse` whose metadata is validated. LOS-0213 remains responsible for mapping error codes to safe RFC Problem Details.
