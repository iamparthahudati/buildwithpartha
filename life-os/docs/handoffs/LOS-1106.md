## Completed behavior

- Implemented authenticated REST endpoint `GET /reports/progress` returning progress aggregations across Task Management, Focus Time, Projects, Goals, Habits, and Reviews.
- Integrated query parameter validation for `startDate`, `endDate`, `timeZone`, `projectId`, `labelId`, and `category`:
  - Validates IANA timezone, returning `400 VALIDATION_FAILED` with `INVALID_TIMEZONE` on invalid timezones.
  - Enforces date order (`startDate <= endDate`), returning `400 VALIDATION_FAILED` with `INVALID_DATE_RANGE` if violated.
  - Enforces bounded SQL execution by capping queries at 366 days (1 year), returning `400 VALIDATION_FAILED` with `RANGE_EXCEEDS_MAXIMUM_BOUND` if exceeded.
- Adheres strictly to canonical Analytics Metric Dictionary (`docs/33-ANALYTICS-METRIC-DICTIONARY.md` v1.0.0):
  - Exposes `metricDictionaryVersion: "1.0.0"` in response metadata.
  - Calculates task completion rate %, overdue, high priority, and blocked counts.
  - Calculates actual focus/break minutes, planned focus minutes, comparison source/minutes, and planned-vs-actual ratio %.
  - Calculates project status breakdowns and average progress %.
  - Calculates goal progress % and recent check-in counts.
  - Calculates daily review completion streak and finalized review counts.
- Generates accessible, factual, non-causal summary text string (`summaryText`) adhering strictly to Section 2.3 Non-Causal Claims Enforcement.
