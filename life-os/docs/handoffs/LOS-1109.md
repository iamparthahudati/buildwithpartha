## Completed behavior

- Implemented authenticated REST Reports API under `/reports` (`ReportController`):
  - `GET /reports/definitions`: Returns catalog metadata for all supported named report types (`TASK_COMPLETION`, `TIME_ALLOCATION`, `PROJECT_PROGRESS`, `GOAL_EXECUTION`, `REVIEW_RITUALS`, `COMPREHENSIVE_PROGRESS`) including supported filter keys, default timeframes, and asynchronous thresholds (`asyncThresholdDays`).
  - `GET /reports/definitions/{reportType}`: Returns metadata for a single named report definition.
  - `GET /reports/generate`: Generates report data payload for specified `reportType` and query filters (`startDate`, `endDate`, `timeZone`, `projectId`, `labelId`, `category`).
  - `GET /reports/named/{reportType}`: Generates report data payload for the named report type specified in path variable.
- Integrated parameter validation:
  - Validates IANA timezone, returning `400 VALIDATION_FAILED` with `INVALID_TIMEZONE` on invalid timezones.
  - Enforces date order (`startDate <= endDate`), returning `400 VALIDATION_FAILED` with `INVALID_DATE_RANGE` if violated.
  - Enforces maximum date range bound of 366 days (1 year), returning `400 VALIDATION_FAILED` with `RANGE_EXCEEDS_MAXIMUM_BOUND` if exceeded.
- Implemented Asynchronous Processing Threshold logic:
  - Compares date range days against report definition `asyncThresholdDays` (90 days).
  - Ranges > 90 days set `isAsynchronous: true`, status `"QUEUED"`, and supply execution `jobId`.
  - Synchronous ranges <= 90 days set `isAsynchronous: false` and status `"COMPLETED"`.
- Built rich, structured report payloads:
  - Summary metrics (`metrics`): Key metrics aligned with Analytics Metric Dictionary v1.0.0 (`v1.0.0`).
  - Tabular breakdowns (`tables`): Formatted data tables for task breakdowns, focus category allocation, project status distribution, goal execution recency, and review streaks.
  - Visualization chart series (`chartSeries`): Data points (`dataPoints`) and chart types (`LINE`, `BAR`, `PIE`, `DONUT`) for frontend charting.
  - Accessible narrative summary text (`summaryText`): Factual, non-causal summary text string adhering strictly to Metric Dictionary Section 2.3.
- Enforced private cache control headers (`Cache-Control: private, no-store, max-age=0, must-revalidate`) and user ownership isolation.
