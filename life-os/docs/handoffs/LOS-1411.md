## Completed behavior

- Implemented structured logging, MDC correlation ID propagation, W3C traceparent tracing context, and sensitive data redaction capabilities:
  - `StructuredJsonLayout` Logback layout (`tech.buildwithpartha.lifeos.common.logging`) formatting log events as structured single-line JSON objects containing `timestamp` (ISO-8601 UTC), `level`, `thread`, `logger`, `message`, `correlationId`, `traceId`, `spanId`, `jobKind`, and structured exception details.
  - `JobCorrelationContext` MDC context utility for background and scheduled job executions, providing auto-closeable `withCorrelationId` and `withJobCorrelation` helpers that populate and clear MDC attributes.
  - Enhanced `CorrelationIdFilter` to extract W3C `traceparent` headers (`version-traceId-spanId-flags`) as well as `X-Trace-ID` / `X-Span-ID` into SLF4J MDC (`traceId`, `spanId`) with deterministic `finally` cleanup.
  - Updated `BackgroundJobWorker` to execute background jobs within `JobCorrelationContext`, ensuring all log entries during job processing contain `correlationId` (`job-<uuid>`) and `jobKind`.
  - Configured `logback-spring.xml` supporting structured JSON logging for `prod` profile and pattern-formatted logging for local/test environments.
  - Added unit and redaction test suite (`StructuredLoggingTests`) verifying JSON layout output, MDC context propagation, W3C traceparent extraction, and secret/credential redaction safety.
