## Completed behavior

- **Created Offline Drafts Domain Module (`src/features/offline-drafts`)**:
  - Implemented `model/draftStorage.ts` for session-scoped local draft persistence under user-bound key namespace (`lifeos.drafts.<userId>.<draftKey>`).
  - Implemented payload encryption/obfuscation (`encryptPayload` / `decryptPayload`) with user-bound salt (`${userId}-lifeos-draft-salt`) so private draft text is not stored in plaintext in local storage.
  - Implemented automatic 7-day default TTL draft expiration (`isDraftExpired`), automatic stale draft pruning, and storage quota protection (`MAX_SINGLE_DRAFT_BYTES` cap and `QuotaExceededError` fallback with oldest-draft eviction).
  - Implemented `clearUserDrafts(userId)` and `clearAllDrafts()` functions to purge local drafts.
  - Implemented `hooks/useOfflineDraft.ts` managing debounced local storage draft persistence, state restoration on mount, and immediate/clear operations.
  - Implemented `components/DeviceDraftBadge.tsx` displaying the canonical `Device draft` status label and timestamp subtext with status live-region announcements (`role="status"`).
  - Exposed module through public entrypoint `index.ts`.
- **Integrated Session Logout Cleanup (`AuthSessionProvider.tsx`)**:
  - Updated `clearSession()` and account switching in `setSession()` to purge all user-scoped offline drafts (`clearUserDrafts` / `clearAllDrafts`) upon logout or user change.
  - Added unit test coverage in `AuthSessionProvider.test.tsx` verifying offline draft cleanup on session termination.
- **Integrated Device Draft Label with Note Form (`NoteForm.tsx`)**:
  - Connected `DeviceDraftBadge` to rendering `offline-unsaved` status and offline editing indications in `NoteForm.tsx`.
- **Quality & Verification**:
  - Passed quality gate (`npm run verify:quality` in `apps/web`) with zero ESLint/TypeScript/boundary errors and zero design token violations.
  - Passed unit test suite for `@features/offline-drafts` (21 tests passing).
  - Passed documentation link validation (`node life-os/scripts/validate-docs.mjs`).
