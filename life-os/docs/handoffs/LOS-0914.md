## Completed behavior

- Built `FocusModeSurface` as a controlled, presentation-first full Focus Mode composition. It does not own the server clock, persisted preferences, browser storage, polling, or cross-tab reconciliation reserved for LOS-0915/LOS-0916.
- Composed the existing controlled `TimerRing` with canonical Focus Session focus/break phases and idle, Running, Paused, Completed, and Cancelled presentations. Timer updates remain visual-only and inherit TimerRing/ProgressRing transition-only announcements and reduced-motion behavior; no per-second live-region announcements were added.
- Added reusable `FocusControls` for Start focus, Pause, Resume, Complete session, Cancel session, and Skip break. Pending actions prevent duplicate activation while retaining accessible action names.
- Added exact confirmations before completion and cancellation. Completion explains that confirmed time is recorded and a linked Task is not marked Done; cancellation explains truthful history retention and that confirmed Task time is not added.
- Added `SessionContext` for optional linked Task and Time Block titles, canonical links, and localized wall-clock text, plus an honest unlinked state.
- Added bounded next-session settings for 1–1,440 focus minutes and 0–180 break minutes. Copy identifies these as editable choices rather than universal recommendations; persisted preference ownership remains LOS-0916.
- Added `InterruptionCapture` for optional private plain-text distraction notes, with a 2,000-character limit, preserved controlled input, explicit save action, pending/error handling, and privacy wording.
- Added deliberate browser-notification consent states for default, allowed, blocked, and unsupported environments. The permission request is exposed only after the user chooses Allow notifications; the component never requests permission on mount.
- Covered loading, unavailable/retry, disabled/reconnect-style, mutation error, focus, break, linked/unlinked, pending, completed, and cancelled states. Completion summaries report confirmed minutes without claiming Task completion.
- Made the surface responsive to its own container so it works as one column in narrow/embedded contexts and two columns on desktop, without horizontal overflow at the catalog's 320px minimum. Mobile actions expand to full width and retain the 44px target contract.
- Added six catalog specimens: Running focus, Paused break, Ready, Completed, Unavailable, and Loading.
