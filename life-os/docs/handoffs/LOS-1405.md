## Completed behavior

Implemented private generated-file lifecycle framework (`tech.buildwithpartha.lifeos.export` and `common.export`) conforming to `02-ARCHITECTURE.md`, `06-SECURITY.md`, `31-PRIVACY-DATA-LIFECYCLE.md`, and `docs/backlog/EPIC-14-BACKEND-OPERATIONS.md`:

- **Database Migration (`V6__export_files_schema.sql`)**:
  - `public.export_files` table with UUID primary key, `user_id` foreign key cascade-deleting with user, optional `job_id` foreign key referencing `public.background_jobs`, `export_kind` constraint (`FULL_DATA_EXPORT`), `status` constraint (`GENERATING`, `READY`, `EXPIRED`, `DELETED`), SHA-256 download token hash storage, expiry timestamps, and size tracking.
  - Partial index `ix_export_files_token_hash` on `download_token_hash WHERE download_token_hash IS NOT NULL`.
  - Partial index `ix_export_files_cleanup` on `updated_at WHERE status IN ('EXPIRED', 'DELETED')` for R1 retention purges.
- **Cross-Domain Port (`tech.buildwithpartha.lifeos.common.export`)**:
  - `ExportFilePort`: Cross-domain port providing quota checks (`MAX_ACTIVE_EXPORTS_PER_USER = 3`), export initialization, storage completion with token generation, download token refresh, and deletion.
  - `ExportFileKind`: Enum defining registered export kinds (`FULL_DATA_EXPORT`).
- **Domain Layer (`tech.buildwithpartha.lifeos.export.domain`)**:
  - `ExportFile`: Immutable domain aggregate enforcing lifecycle transitions (`GENERATING -> READY -> EXPIRED / DELETED`), download token validation, quota state checks, and download timestamp recording.
  - `ExportFileStatus`: Enum covering export lifecycle.
  - `ExportFileRepository`: Port defining save, findById, findByDownloadTokenHash, findByUserId, countActiveByUserId, findOverdueReady, and deleteTerminalOlderThan.
- **Application Layer (`tech.buildwithpartha.lifeos.export.application`)**:
  - `ExportFileService`: Manages export metadata, quota guard, token issuance, deletion, overdue expiration, and R1 retention purges.
  - `ExportDownloadService`: Validates download token, verifies user ownership and file status, opens private storage stream, and records download timestamp.
  - `ExportTokenService`: Cryptographically secure random token generation (32-byte hex) and SHA-256 hashing.
  - `ExportStoragePort`: Port abstraction for private storage operations (store, read, delete, exists).
  - `ExportFileCleanupJob`: `@Scheduled(cron = "0 0 4 * * *")` daily purge expiring overdue exports and removing orphaned files from storage.
- **Infrastructure Layer (`tech.buildwithpartha.lifeos.export.infrastructure`)**:
  - `ExportFileEntity`: JPA entity mapping to `public.export_files`.
  - `ExportFileJpaRepository`: Spring Data JPA repository.
  - `JpaExportFileRepository`: Implements `ExportFileRepository`.
  - `LocalExportFileStorage`: Local filesystem implementation storing files under private storage path (`lifeos.export-storage-path`) with non-predictable UUID filenames.
  - `ExportFilePortAdapter`: Implements `common.export.ExportFilePort`.
- **Architecture & Rules**:
  - `PackageBoundaryRules.java` approves `"export"` domain package.
  - Updated test `schema.sql` and `scripts/verify-flyway-postgres.sh`.
