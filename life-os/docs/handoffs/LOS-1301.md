## Completed behavior

- **Global Search REST API (`GET /life-os/api/v1/search`)**:
  - Implemented authenticated, owner-scoped global search across all six approved entities: **Projects**, **Tasks**, **Notes**, **Brain Dump Items**, **Goals**, and **Habits**.
  - Supports query parameter `q` for search text, `types`/`type` for filtering specific entity types (`PROJECT`, `TASK`, `NOTE`, `BRAIN_DUMP`, `GOAL`, `HABIT`), and pagination parameters (`page`, `size`).
  - Returns a rich response envelope (`SearchResponse`) combining:
    - Standard pagination metadata (`page`, `size`, `totalItems`, `totalPages`).
    - Summary counts per entity type (`counts`).
    - Grouped results per entity type (`groups`) for command palette views.
    - Flat paginated item results (`items`) sorted by relevance score descending and `updatedAt` descending.
  - Excludes deleted tasks (`deleted_at IS NULL`) and non-owned records.
  - Relevance ranking scores exact title matches highest (100), title prefix matches (80), title contains (60), and body matches (30).
  - Safe HTML escaping prevents XSS while inserting `<mark>` tags around matched terms in titles and extracted body snippets.
  - Implemented `[REDACTED]` in `toString()` overrides across all DTOs, domain models, and commands to guarantee search queries and body text are never logged.
