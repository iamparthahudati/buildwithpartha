## Completed behavior

- Added `TaskSummaryMetrics`, a controlled six-card summary for All, To Do, In progress, Done, Blocked, and Overdue counts composed from the shared `MetricCard`.
- Added exact, accessible filter action names and `aria-pressed` state. A polite atomic status summarizes changed counts, loading and failure states without making color the only selection cue.
- Added ready, loading, no-tasks, error/retry and disabled-action behavior. One shared summary failure renders on every affected value but exposes only one retry action.
- Added pure URL preset helpers. Applying a preset uses the task query API's `status` and `overdue` keys, removes conflicting preset keys, preserves unrelated Task filters and sort/view state, resets `page`, and never mutates the caller's `URLSearchParams`.
- Added strict preset parsing. URLs with custom or unknown combinations return `null` instead of incorrectly marking All as selected.
- Added interactive catalog specimens for ready, loading, no-tasks, and error states.
