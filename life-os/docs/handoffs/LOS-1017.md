## Goal

Make the **Add Task to Sprint** dialog easier to use when tasks span multiple projects: pick a
project first, then the task dropdown shows only that project's tasks.

## Behavior

- A **Project** select is added above the **Task** select in `SprintTaskDialog`.
- Options: **All projects** (default, shows everything), one entry per distinct project among the
  candidate tasks, and **No project** when any candidate task has no project.
- Choosing a project narrows the Task select to that project's tasks. Changing the project clears a
  previously selected task if it no longer matches the filter.
- The Project filter is **auto-hidden** when it would not help: fewer than two project groups are
  present (i.e. all tasks share one project, or none have a project), or the dialog is in edit mode
  (the task is fixed and its Select is disabled).
- Frontend only — no API, schema, or story-points change. Story points still default to 1 and remain
  editable per commitment (unchanged).

## Files

- `sprints/components/SprintTaskDialog.tsx` — `SprintTaskOption` gains optional `projectId` /

- `routes/SprintsRoute.tsx` — supplies `projectId` / `projectName` on each task option.
- `sprints/components/SprintTaskDialog.test.tsx` — new: filter narrows options; filter hidden with a
