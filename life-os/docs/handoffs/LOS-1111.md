## Completed behavior

- Implemented RFC 4180-compliant CSV export support for all 6 named report types:
  - **Metadata Header**: Prepend rows at the top of the CSV file representing name, type, period bounds, generated timestamp, timezone, and metric dictionary version.
  - **Summary Metrics**: Includes a dedicated section presenting summary metrics from the metric dictionary.
  - **Tabular Sections**: Outputs all data tables sequentially with their headers, data rows, and titles.
  - **Formula Injection Protection**: Prefixes any dangerous cell values starting with `=`, `+`, `-`, or `@` with a single-quote (`'`) to neutralize malicious formula execution in spreadsheet applications.
  - **UTF-8 with BOM Encoding**: Writes the byte-order mark (`\xEF\xBB\xBF`) at the start of the file for auto-detection in Excel and other spreadsheet viewers.
- Private generated-file token lifecycle (LOS-1405 integration):
  - Integrates with `ExportFilePort` to register `REPORT_CSV_EXPORT` kind.
  - Stores physical CSV files in private storage under unique filenames.
  - Issues a cryptographically random, short-lived (15 minutes) download token.
- Secure private download:
  - Adds endpoints to `CsvExportController`:
    - `POST /reports/export/csv` to generate the file and return the metadata and download token.
    - `GET /reports/export/csv/download` to redeem the token and stream the file with `Content-Type: text/csv; charset=UTF-8` and `Content-Disposition: attachment`.
  - Restricts download to the authenticated session user who requested the export. Other users receive `404 Not Found`.
- Frontend integration:
  - Adds `ReportExportButton` next to the print action in the `PageHeader` of `ReportsScreen`.
  - Triggers a browser-native file download on mutation success by dynamically creating a temporary download anchor link.
  - Correctly disables during loading states and handles potential API errors with an accessible error display.
