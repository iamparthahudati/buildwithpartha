## Completed behavior

### Data Export, Deletion Lifecycle & Privacy Verification (`31-PRIVACY-DATA-LIFECYCLE.md`)

Formally audited and verified data portability, secret exclusion, multi-tenant export isolation, account deletion grace period lifecycle, immediate session revocation, uncancelled deletion cascade purge, and minimal non-PII audit ledger retention across all LifeOS domain boundaries:

1. **Complete Data Export & Portability across all 19 Domain Entities**:
   - Implemented 16 domain `UserDataExportContributor` implementations across all domain aggregates in `apps/api`:
     - `TaskExportContributor.java` (`tasks.json` — tasks and subtasks)
     - `ProjectExportContributor.java` (`projects.json` — projects and milestones)
     - `LabelExportContributor.java` (`labels.json` — user labels and color swatches)
     - `TimeBlockExportContributor.java` (`timeblocks.json` — time allocations)
     - `FocusSessionExportContributor.java` (`focus_sessions.json` — sessions and interruptions)
     - `SprintExportContributor.java` (`sprints.json` — sprint goals and task commitments)
     - `WeeklyPlanExportContributor.java` (`weekly_plans.json` — week plan outcomes, items, capacities)
     - `ReviewExportContributor.java` (`reviews.json` — daily/weekly/monthly review retrospectives and rollover decisions)
     - `GoalExportContributor.java` (`goals.json` — goals, check-ins, linked target entities)
     - `NoteExportContributor.java` (`notes.json` — markdown notes and target entity links)
     - `BrainDumpExportContributor.java` (`braindump.json` — brain dump items and statuses)
     - `HabitExportContributor.java` (`habits.json` — habits, target cadences, completion logs)
     - `NotificationExportContributor.java` (`notifications.json` — notifications and read statuses)
     - `ProductActivityExportContributor.java` (`activity.json` — product activity event stream)
     - `CommentExportContributor.java` (`comments.json` — task/project comments)
     - `AttachmentMetadataExportContributor.java` (`attachments.json` — attachment metadata and storage keys)
   - Updated `ExportArchiveBuilder.java` to inject `timeZone` and `locale` into `manifest.json`, fully conforming to `docs/schemas/data-export.schema.json`.
   - Core export metadata includes `manifest.json`, `account.json`, `terms.json`, `preferences.json`, and user guide `README.md`.

2. **Strict Exclusion of Secrets & Security Credentials**:
   - Argon2 password hashes (`credentials.password_hash`) are strictly excluded.
   - Session token hashes (`user_sessions.token_hash`), CSRF secrets, and password reset / email verification tokens are excluded.
   - Raw cookies and authorization headers are never captured.

3. **Multi-Tenant Export Isolation**:
   - All export query streams enforce strict user ID scoping (`WHERE user_id = :userId`).
   - Cross-user tenant isolation verified with zero foreign records across any generated export archive file.

4. **Account Deletion 30-Day Grace Period & Session Revocation**:
   - Account deletion requires re-authentication with current password and matching confirmation text.
   - Account transitions to `PENDING_DELETION` status and enters a 30-day grace period (`GRACE_PERIOD`).
   - All active user sessions across all devices are immediately revoked (`revoked_at = now`), returning 401 Unauthorized for subsequent requests.

5. **Deletion Cancellation & Account Restoration**:
   - Within the 30-day grace period, users can cancel deletion using a secure cancellation token sent via email, restoring account status to `ACTIVE`.

6. **Automated Cascade Purge & Minimal Non-PII Audit Ledger**:
   - Upon expiry of the 30-day grace period, `AccountDeletionPurgeService` executes the automated purge sweep.
   - Primary user deletion triggers database-level `ON DELETE CASCADE` across all child entities.
   - The deletion request row in `account_deletion_requests` is marked as `PURGED` and preserved with minimal non-PII metadata (opaque former ID and timestamps) per R6/R8 retention requirements.
