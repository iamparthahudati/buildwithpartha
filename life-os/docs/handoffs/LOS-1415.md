## Completed behavior

- Replaced all stub Today widget providers with real-data domain aggregations across every Today widget:
  - **Most Important Task (`DefaultMitWidgetProvider`)**: Queries domain MIT task for the user's local date, enriched with project name, project color, status, and priority. Returns `EMPTY` when no MIT is selected.
  - **Today Tasks (`DefaultTasksWidgetProvider`)**: Aggregates tasks scheduled for today or due today, prioritizes MIT, surfaces next up tasks, counts overdue tasks, and enriches project context without N+1 queries.
  - **Schedule & Timeline (`DefaultScheduleWidgetProvider`)**: Fetches time blocks for the user's local date, computes block status (`CURRENT`, `COMPLETED`, `SCHEDULED`), detects pairwise overlapping schedule conflicts, and enriches linked task/project metadata.
  - **Current & Next Block (`DefaultCurrentNextBlockWidgetProvider`)**: Identifies the currently running time block and the next immediate scheduled time block based on current instant. Returns `EMPTY` when no current/next blocks exist.
  - **Overdue Tasks (`DefaultOverdueWidgetProvider`)**: Queries tasks with due dates prior to today that remain uncompleted, returning the count and priority-sorted list.
  - **Active Sprint (`DefaultSprintWidgetProvider`)**: Fetches active sprint details, start/end dates, total committed story points, completed story points via single join query (`sprint_tasks` + `tasks`), and days remaining. Returns `EMPTY` when no sprint is active.
  - **Weekly Plan (`DefaultWeekWidgetProvider`)**: Retrieves the weekly plan for the current week, target outcomes, allocated items, and completion progress. Returns `EMPTY` when no weekly plan is drafted or finalized.
  - **Active Projects (`DefaultActiveProjectsWidgetProvider`)**: Fetches active projects and single-query batch aggregated open/completed task counts (`GROUP BY project_id`), resolving project health, progress, and color.
  - **Daily Reviews (`DefaultReviewWidgetProvider`)**: Retrieves morning and evening daily review statuses and summaries for today. Returns `EMPTY` when reviews have not been started.
  - **Today Metrics Strip (`DefaultMetricsWidgetProvider`)**: Aggregates metrics reconciling with source screens: completed tasks today, overdue tasks count, active projects count, and habit completion stats for today.
- Preserved strict architectural boundaries and ArchUnit package isolation rules using decoupled domain ports in `tech.buildwithpartha.lifeos.common.*` and domain-specific infrastructure adapters in `task`, `project`, `focus`, `timeblock`, `sprint`, `goal`, `habit`, and `braindump`.
- Implemented error isolation per provider so individual provider errors degrade gracefully to `ERROR` status while preserving the remaining dashboard sections.
